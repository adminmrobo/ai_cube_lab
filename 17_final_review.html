행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

숫자 함수 f에 쓰면 ∇f(화살표), 화살표 v와 「성분끼리 곱해 더하기」 하면 ∇·v(숫자), 「엇갈려 빼기」 하면 ∇×v(바람개비).

1단계 · 델 연산자 가족 지도

방법: ∇의 쓰임 분류일상: 가족 관계도
박사

상황 질문 — 처음 보는 공식에서 ∇를 만났을 때, 무엇부터 확인하면 그 공식이 누구인지 알 수 있을까요?

왜 이 방법을 쓰나

  1. 문제 상황: 여섯 가지 도구(∇f, J, H, ∇·, ∇×, ∇²)를 한 장에 정리하고 싶어요.
  2. 앞 방법의 한계: 장마다 따로 배워서 서로 어떤 관계인지 흐릿해요.
  3. 해법: 「무엇을 넣어서 무엇이 나오나」(입력·출력의 종류)로 분류해요. 숫자 → 화살표(∇f), 화살표 → 표(J), 화살표 → 숫자(∇·), 화살표 → 바람개비(∇×), 숫자 → 숫자(∇², 2차).
쉽게 말하면 — 들어가는 것과 나오는 것만 보면 누구인지 안다.

여섯 개가 다 ∇를 쓰는데, 어떻게 이렇게 다른 결과가 나와요?

학교 수학으로 보면: 02장 벡터의 곱 두 가지(성분끼리 곱해 더하기, 엇갈려 빼기)와 03장 행렬을 ∇에 적용한 것이에요.

식 조각읽는 법뜻
∇f숫자 함수 → 화살표편미분을 나란히
∇·v, ∇×v화살표 밭 → 숫자 / 바람개비같은 짝을 더하기 / 엇갈린 짝을 빼기
J, H표그래디언트를 쌓은 표 / 그래디언트의 야코비안
숫자로 한 번 해 보기

f = x² + y²: ∇f = (2x, 2y) (화살표)

J(∇f) = H = 2, 0], [0, 2 (표)

∇·(∇f) = 2 + 2 = 4 = ∇²f = H의 대각선 합 (숫자)

∇×(∇f) = ∂(2y)/∂x − ∂(2x)/∂y = 0 − 0 = 0 (바람개비 안 돎)

함수 하나로 가족 전체를 다 계산해 봤어요! 모두 하나에서 갈라져 나왔네요.

가족 관계도는 「누가 누구의 자식인가」만 보면 한눈에 정리돼요. 델 연산자 가족도 「무엇에서 무엇이 나오나」만 보면 돼요.

수학에서는

델 연산자 ∇는 「편미분 모음」이에요. 숫자 함수에 쓰면 그래디언트, 화살표와 짝지어 더하면 발산, 엇갈려 빼면 회전, 그래디언트에 다시 쓰면 헤시안·라플라시안이 돼요.

박사

카드를 하나씩 눌러 「들어가는 것 → 나오는 것」을 확인해 보세요.

인턴 시아

저는 「높이 → 화살표 → 숫자」 순서로 외웠어요: ∇f 다음 ∇·(∇f) = ∇²f.

초파리 연구원

헤시안 카드를 봐. 누구의 야코비안이라고 써 있어?

델 연산자 가족 카드 — 눌러서 한 줄 요약 보기

풀이 — 한 걸음씩

  1. 그래디언트는 숫자 함수에서 화살표를 만들어요.
  2. 발산과 회전은 화살표 밭에서 숫자(또는 바람개비 화살표)를 만들어요.
  3. 야코비안은 여러 출력의 그래디언트를 쌓은 표, 헤시안은 그래디언트의 야코비안이에요.
  4. 라플라시안은 그래디언트의 발산 — 「높이 → 화살표 → 숫자」로 한 바퀴 돌아와요.
이 단계의 한계 — 가족 지도는 3차원 이하의 매끄러운 함수를 기준으로 그렸어요. 고차원·매끄럽지 않은 함수에서는 더 조심해야 해요.
박사의 해석 — 새 공식을 만나면 「∇가 무엇에 쓰였나, 결과가 숫자·화살표·표 중 무엇인가」부터 보세요. 그러면 가족 중 누구인지 알 수 있어요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ②: 「∇ gives the four central operations of vector calculus」 — 그래디언트, 발산, 회전, 라플라시안. 원자료 ①의 야코비안·헤시안을 더해 여섯 가족이에요.

상황 질문 — 산을 한 바퀴 돌아 출발점으로 돌아오면 오르내린 높이의 합은 얼마일까요?

왜 이 방법을 쓰나

  1. 문제 상황: 계산 결과를 빠르게 검산할 「언제나 성립하는 관계」를 알고 싶어요.
  2. 앞 방법의 한계: 공식 하나하나를 다시 계산해 확인하는 건 느려요.
  3. 해법: 언제나 성립하는 두 관계를 써요: 그래디언트의 회전은 0(∇×∇f = 0), 그래디언트의 발산은 라플라시안(∇·∇f = ∇²f).
쉽게 말하면 — 오르막 화살표만으로는 소용돌이를 못 만든다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

왜 그래디언트의 회전은 「언제나」 0이에요?

학교 수학으로 보면: 14장의 「섞인 편미분은 순서를 바꿔도 같다」 덕분이에요. 회전 = ∂(∂f/∂y)/∂x − ∂(∂f/∂x)/∂y = (같은 값) − (같은 값) = 0.

식 조각읽는 법뜻
∇×(∇f) = 0기울기의 회전섞인 편미분이 같아서 언제나 0
∇·(∇f) = ∇²f기울기의 발산라플라시안의 정의 그대로
검산쓰임계산한 그래디언트의 회전이 0이 아니면 어딘가 틀림
숫자로 한 번 해 보기

f = x²y: ∇f = (2xy, x²)

회전: ∂(x²)/∂x − ∂(2xy)/∂y = 2x − 2x = 0

발산: ∂(2xy)/∂x + ∂(x²)/∂y = 2y + 0 = 2y

∇²(x²y) = ∂²/∂x² + ∂²/∂y² = 2y + 0 = 2y ✓ 같음

조수 하루 (수강생)

산을 한 바퀴 돌면 높이 변화가 0인 것처럼, 오르막 화살표 밭은 돌 수가 없구나.

일상으로 치면

산길을 한 바퀴 돌아 출발점에 오면, 오른 만큼 내려와서 높이 변화의 합이 0이에요. 「높이」에서 나온 화살표는 빙글빙글 돌 수 없어요.

수학에서는

관계식 ∇×(∇f) = 0, ∇·(∇f) = ∇²f. 경사 하강의 길(−∇f 흐름)은 회전이 없어서 빙글빙글 맴돌지 않아요. 계산 검산에도 쓰여요.

  1. f = x²y의 그래디언트 (2xy, x², 0)의 회전은 공식·숫자 모두 0이에요.
  2. f = x² + y²의 그래디언트 (2x, 2y)의 발산은 4, 라플라시안도 4예요.
  3. 그래디언트를 계산했는데 회전이 0이 아니면, 그래디언트 계산 어딘가가 틀린 거예요.
  4. 13장 소용돌이 (−y, x)는 회전이 2라서, 어떤 높이 f의 그래디언트도 될 수 없어요.
이 단계의 한계 — 「언제나 0」은 매끄러운 함수(섞인 편미분이 같은 함수)에서 성립해요. 13장 가운데 빼고 도는 흐름처럼 구멍이 있는 곳은 따로 조심해야 해요.
박사의 해석 — 관계식은 공짜 검산 도구예요. AI 개발에서도 기울기 계산 코드를 검사할 때 이런 「언제나 성립해야 하는 성질」을 확인해요.
3

3단계 · 졸업 발표 — AI 속 미분 지도

방법: 개념과 AI의 연결일상: 교실 졸업 앨범
박사

상황 질문 — AI 뉴스에서 「학습률」, 「역전파」, 「안장점」, 「확산 모델」이라는 말을 들으면, 이 교실의 몇 장으로 돌아가면 될까요?

왜 이 방법을 쓰나

  1. 문제 상황: 배운 도구가 AI의 어디에 쓰이는지 한 번에 정리하고 싶어요.
  2. 앞 방법의 한계: 개념을 장별로 배워서 AI 전체 그림과 연결이 흐릿해요.
  3. 해법: AI의 주요 부분(데이터 표현, 층, 학습, 역전파, 최적화의 어려움, 이미지·생성)마다 해당 도구와 장 번호를 잇는 카드를 만들어요.
쉽게 말하면 — AI 용어 하나 = 이 교실의 장 하나.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

이걸 다 알아야 AI를 쓸 수 있어요?

학교 수학으로 보면: 아니에요. 계산은 프로그램이 해요. 다만 「이 숫자가 무엇을 뜻하나, 그럴듯한가」를 판단할 때 이 지도가 쓰여요.

식 조각읽는 법뜻
데이터 = 벡터01·02·05장비슷함 = 가까움, 방향
층 = 행렬 × 벡터03장늘이고 돌리는 기계
학습 = 경사 하강, 역전파 = 야코비안 곱09·10·11장AI가 배우는 방법
어려움 = 헤시안(휨·안장), 이미지·생성 = 라플라시안·발산07·12·14·15장AI가 막히는 곳과 쓰는 곳
숫자로 한 번 해 보기

「학습이 발산했다」 → 10장: 학습률이 휨에 비해 너무 큼

「기울기 소실」 → 11장: 1보다 작은 국소 기울기를 계속 곱함

「안장점에서 정체」 → 07·14장: 기울기 0이지만 바닥이 아님

「경계 검출」 → 15장: 라플라시안 필터

조수 하루 (수강생)

AI 뉴스 용어가 다 교실 장 번호로 바뀌네요. 이제 겁나지 않아요!

일상으로 치면

졸업 앨범을 넘기면 장마다 함께한 친구가 떠오르듯, AI 용어를 들으면 이 교실의 장이 떠오르게 만드는 게 목표예요.

수학에서는

AI 속 미분 지도: 데이터(벡터) → 층(행렬) → 학습(그래디언트·경사 하강) → 역전파(야코비안) → 최적화의 어려움(헤시안) → 이미지·생성(라플라시안·발산). 계산은 프로그램이, 판단은 사람이.

그럼 저는 이제 AI를 다 이해한 거죠!

AI 속 미분 지도 — 카드를 눌러 연결된 장 보기

풀이 — 한 걸음씩

  1. 데이터를 벡터로 보는 것이 모든 출발점이에요(01·02·05장).
  2. 학습은 그래디언트, 역전파는 야코비안, 학습의 어려움은 헤시안이 설명해요.
  3. 이미지·생성 모델에는 라플라시안과 발산이 쓰여요.
  4. 마지막 장 실전 연습장에서 이 지도를 직접 써 봐요.
이 단계의 한계 — 이 지도는 입문용으로 단순하게 그렸어요. 실제 AI에는 확률·통계, 최적화 기법, 데이터 처리 등 이 교실 밖의 도구도 많이 쓰여요.
박사의 해석 — 계산은 AI와 프로그램이 1초 만에 해요. 이 교실에서 기른 힘은 「그 결과가 무엇을 뜻하고, 그럴듯한가」를 판단하는 힘이에요.

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

졸업 전 마지막 AI 판단 코너. 시아가 AI에게 「헤시안과 라플라시안의 관계」를 물었더니 이렇게 답했어요.

AI 답변: 헤시안은 그래디언트의 발산이고, 라플라시안은 헤시안의 행렬식입니다.
박사

마지막 조언이에요. AI의 설명이 그럴듯해도 「결과의 종류(숫자·화살표·표)가 맞나」와 「작은 예 하나로 맞나」를 확인하세요. 이 두 질문이 이 교실의 졸업 선물이에요.

조교 대결 — ∇·(∇f)와 ∇²f, 누구 길이 맞을까?

f = x² + y²에 대해 초파리는 「그래디언트를 구한 뒤 발산」, 주판봇은 「라플라시안 공식으로 바로」 계산했어요.

초파리 연구원

「∇f = (2x, 2y), 발산하면 2 + 2 = 4.」

VS
주판봇

「라플라시안 2 + 2 = 4!」

누가 맞을지 먼저 예상해 보고 단추를 누르세요. 판정은 계산 결과로만 합니다.
