y = x²은 아래로 볼록(∪), y = −x²은 위로 볼록(∩). 부호 하나가 방향을 뒤집어요.

1

1단계 · 말안장 — 앞뒤로는 바닥, 옆으로는 꼭대기

방법: 쌍곡포물면과 안장점일상: 말안장, 프링글스 과자
박사

상황 질문 — 말안장 가운데에 구슬을 올려 두면 구슬은 가만히 있을까요? 살짝 옆으로 밀면?

왜 이 방법을 쓰나

  1. 문제 상황: 「평평하지만 바닥은 아닌 곳」을 식으로 나타내고 싶어요.
  2. 앞 방법의 한계: 그릇 식 z = x² + y²에서는 평평한 곳이 늘 바닥이었어요.
  3. 해법: z = y²/b² − x²/a²: y 방향으로는 ∪(그릇), x 방향으로는 ∩(돔). 가운데는 평평하지만 한쪽으로는 내려가요.
쉽게 말하면 — 한 방향은 오르막, 다른 방향은 내리막이 만나는 곳.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

y²에서 x²을 빼면 왜 말안장이 돼요?

학교 수학으로 보면: 중학교 3학년 이차함수 y = x²(∪)과 y = −x²(∩)을 서로 직각인 두 방향에 붙인 모양이에요.

식 조각읽는 법뜻
z = y² − x²쌍곡포물면 (a = b = 1)말안장
x = 0으로 자르기z = y²∪ 모양 — 가운데가 바닥
y = 0으로 자르기z = −x²∩ 모양 — 가운데가 꼭대기
숫자로 한 번 해 보기

원점 (0, 0): z = 0

(0, 1): z = 1 > 0 (y 방향은 올라감)

(1, 0): z = −1 < 0 (x 방향은 내려감)

(0.1, 0): z = −0.01 — 원점 바로 옆에도 더 낮은 곳이 있음 → 원점은 최저점이 아님

조수 하루 (수강생)

가운데가 평평하긴 한데, 옆으로 조금만 가도 더 낮은 곳이 있네요. 바닥이라고 착각하기 딱 좋은 자리예요.

말안장 가운데의 구슬은 앞뒤로는 굴러 돌아오지만, 옆으로 살짝만 밀어도 아래로 떨어져요.

쌍곡포물면 z = y²/b² − x²/a²의 가운데는 안장점이에요. 기울기는 0이지만 최저점도 최고점도 아니에요. AI 학습이 안장점 근처에서 한동안 멈춘 듯 보이기도 해요.

풀이 — 한 걸음씩

  1. 말안장을 돌려 보면 한 방향은 ∪, 다른 방향은 ∩이에요.
  2. 높이 0에서 자르면 단면이 엇갈린 두 직선이에요. 가운데에서 X자로 만나요.

이 단계의 한계 — 「한 방향은 ∪, 다른 방향은 ∩」을 눈으로 확인하려면 방향을 잘 골라야 해요. 비스듬히 놓인 안장은 14장 헤시안의 계산으로 판정해요.

2단계 · 부호 놀이 — 모래시계, 두 그릇, 원뿔

방법: 이차곡면의 부호 분류일상: 냉각탑과 고깔
박사

상황 질문 — 공의 식 x² + y² + z² = 1에서 z² 앞의 부호만 빼기로 바꾸면, 어떤 모양이 될까요?

왜 이 방법을 쓰나

  1. 문제 상황: 비슷하게 생긴 식들이 어떤 모양인지 빨리 알아보고 싶어요.
  2. 앞 방법의 한계: 이차곡면 식은 모두 x², y², z²으로 비슷하게 생겨서 하나하나 그려 보기 어려워요.
  3. 해법: 「빼기 부호가 몇 개인가」와 「오른쪽이 1인가 0인가」만 보고 분류해요.
쉽게 말하면 — 빼기 0개 = 공, 1개 = 모래시계, 2개 = 두 그릇, 오른쪽 0 = 원뿔.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

빼기 하나 바꿨을 뿐인데 정말 모양이 완전히 달라져요?

학교 수학으로 보면: 분수 없이 a = b = c = 1로 두면 식이 x² + y² ± z² = 1 꼴이라, 부호와 오른쪽 수만 비교하면 돼요.

식 조각읽는 법뜻
x² + y² − z² = 1일엽쌍곡면모래시계 한 장 (허리 반지름 1)
z² − x² − y² = 1이엽쌍곡면마주 본 두 그릇 (|z| < 1에는 아무것도 없음)
z² = x² + y²원뿔오른쪽이 0이면 꼭짓점에서 만나는 고깔
숫자로 한 번 해 보기

모래시계: z = 0에서 x² + y² = 1 (반지름 1), z = 1에서 x² + y² = 2 (반지름 √2 ≈ 1.41)

두 그릇: z = 0에서 −x² − y² = 1 → 불가능, 그래서 가운데가 비어 있음

두 그릇: z = 2에서 x² + y² = 3 → 반지름 √3 ≈ 1.73

원뿔: z = 1에서 반지름 1, z = 2에서 반지름 2

조수 하루 (수강생)

높이를 하나씩 넣어 단면 반지름을 재 보니 모양이 그려지네요. 부호 하나가 정말 다 바꾸는구나.

일상으로 치면

발전소 냉각탑은 허리가 잘록한 모래시계(일엽쌍곡면), 고깔모자는 원뿔이에요. 모래시계 위아래를 떼어 낸 듯한 두 그릇도 있어요.

수학에서는

이차곡면 ±x² ± y² ± z² = 1(또는 0)은 빼기 부호의 개수로 공·모래시계·두 그릇·원뿔이 갈려요. 14장에서 헤시안의 부호로 그릇·돔·안장을 가르는 것과 같은 방법이에요.

(두 그릇 역) …저는 가운데가 비어 있어요. 두 장이라서요.

초파리 연구원

빼기를 셋 다 넣어 봐. 무슨 모양이 나오는지.

부호 놀이 — ± 단추로 이차곡면 만들기

풀이 — 한 걸음씩

  1. 빼기 0개, 오른쪽 1 → 공(타원면).
  2. 빼기 1개 → 모래시계 한 장. 빼기가 붙은 축 방향으로 뚫린 모양이에요.
  3. 빼기 2개 → 마주 본 두 그릇. 더하기가 남은 축 방향으로 열려요.
  4. 오른쪽 0 → 원뿔. 빼기 3개(오른쪽 1)는 음수의 합이 1이 될 수 없어 점이 하나도 없어요.
이 단계의 한계 — 여기서는 a = b = c = 1로 단순하게 봤어요. a, b, c가 다르면 단면이 원 대신 타원이 될 뿐, 분류는 같아요.
박사의 해석 — 모양을 가르는 건 숫자의 크기가 아니라 부호예요. 이 「부호로 모양 판정」이 14장 헤시안 판정의 바탕이에요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ④의 HYPERBOLOID OF ONE SHEET, HYPERBOLOID OF TWO SHEETS, ELLIPTIC CONE.

3

3단계 · 이차곡면 밖의 친구들 — 접은 종이, 도넛, 원숭이 안장, 종

방법: 여러 차수의 곡면일상: 도넛과 종
박사

상황 질문 — 원자료 도감에 도넛과 종 모양도 있어요. 이들도 공과 같은 「이차곡면」 가족일까요?

왜 이 방법을 쓰나

  1. 문제 상황: 도감의 나머지 모양도 같은 눈으로 읽고 싶어요.
  2. 앞 방법의 한계: 「이차식」 규칙(부호 분류)은 x, y, z의 2차식에만 통해요. 3차식·지수함수는 그 규칙 밖이에요.
  3. 해법: 식의 차수(가장 높은 거듭제곱)를 먼저 보고, 2차가 아니면 단면과 그림으로 모양을 읽어요.
쉽게 말하면 — 먼저 「몇 차 식인가」, 그다음 단면.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

exp(−(x² + y²))는 처음 보는 기호예요. 겁이 나요.

학교 수학으로 보면: 중학교 지수 2³ = 8처럼 「거듭제곱」이에요. exp(t)는 약 2.718을 t번 곱한 수예요. t가 음수로 커질수록 0에 가까워져요.

식 조각읽는 법뜻
x² = 2py포물기둥 (2차)포물선을 위아래로 쭉 민 모양 — 이차곡면
(R − √(x² + y²))² + z² = r²토러스 (4차)도넛. 큰 반지름 R, 단면 원 반지름 r
z = x³ − 3xy²원숭이 안장 (3차)골짜기 셋 — 원숭이는 꼬리 자리까지
z = exp(−(x² + y²))가우스 곡면가운데 높이 1인 종 모양
숫자로 한 번 해 보기

가우스: (0, 0) → exp(0) = 1 (꼭대기)

(1, 0) → exp(−1) ≈ 0.37, (2, 0) → exp(−4) ≈ 0.018

원숭이 안장: (1, 0) → 1, (−1, 0) → −1, (0, 1) → 0

토러스 R = 2, r = 0.5: 점 (2.5, 0, 0) → (2 − 2.5)² + 0 = 0.25 = 0.5² ✓

조수 하루 (수강생)

종 모양은 가운데서 멀어질수록 빠르게 0에 가까워지네요. 숫자를 넣어 보니 기호가 덜 무서워요.

일상으로 치면

반으로 접은 종이(포물기둥), 도넛(토러스), 꼬리까지 걸치는 원숭이 안장, 종(가우스 곡면)은 모두 도감 친구지만 식의 차수가 달라요.

수학에서는

원자료 도감 11종 중 8종이 이차곡면이고, 토러스(4차)·원숭이 안장(3차)·가우스 곡면(지수함수)은 이차곡면이 아니에요. 가우스 곡면은 정규분포와 AI의 「거리에 따라 줄어드는 유사도」에 쓰여요.

조수 하루

(종 모양 역) 저는 가운데가 1이고 사방으로 부드럽게 줄어들어요.

주판봇

도감에 같이 있으니 다 이차곡면이죠!

초파리 연구원

원숭이 안장 식을 봐. x³이 있어. 2차야?

곡면 도감 ⑤ — 이차곡면 밖의 친구들

풀이 — 한 걸음씩

  1. 포물기둥은 어느 높이에서 잘라도 같은 포물선이에요. 이차곡면 가족이에요.
  2. 토러스를 높이 0 근처에서 자르면 고리 두 개(안팎 원), 꼭대기 근처에서는 고리 하나로 붙어요.
  3. 원숭이 안장은 높이 0에서 자르면 세 갈래로 갈라진 선이 나와요. 내려가는 골짜기가 셋이에요.
  4. 가우스 곡면은 높이가 높을수록 단면 원이 작아져요. 높이 1 위로는 단면이 없어요.
이 단계의 한계 — 이차곡면의 부호 분류는 2차식에만 통해요. 원숭이 안장의 가운데는 휨(2차)이 0이라 14장의 헤시안 판정도 「보류」가 나와요.
박사의 해석 — 모양을 읽는 순서: ① 몇 차 식인가 ② 단면을 몇 높이에서 잘라 보기 ③ 바닥·꼭대기·안장이 어디인지. 이 순서는 AI의 손실 지형을 읽을 때도 그대로 써요.
원자료 인포그래픽 보기 (영어 그림)

원자료 도감은 11가지 곡면을 한 표에 나란히 담았지만, 토러스·원숭이 안장·가우스 곡면은 이차곡면(x, y, z의 2차식)이 아니에요. 이 페이지에서는 「이차곡면 8종 + 그 밖의 곡면 3종」으로 나눠 소개합니다.

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

하루가 AI 학습 기록을 보여 주며 물었어요: 「손실 함수 z = y² − x²에서 출발점이 원점이었고, 기울기가 0이라 학습이 멈췄어요. 원점이 최적인가요?」

AI 답변: 기울기가 0이면 더 내려갈 곳이 없다는 뜻이므로 원점이 손실이 가장 작은 최적점입니다.
박사

「기울기가 0이니 끝났다」는 말을 들으면, 주변 몇 방향의 값을 직접 넣어 보세요. 더 낮은 곳이 하나라도 있으면 바닥이 아니에요. 14장에서 이걸 헤시안으로 한 번에 판정해요.
