야코비안 — 출력이 여러 개일 때의 기울기 표

핵심 질문 — 입력도 여러 개, 출력도 여러 개인 함수의 「기울기」는 어떻게 적을까?

09장 그래디언트는 출력이 하나(높이)일 때의 기울기였어요. 출력이 여러 개면 출력마다 그래디언트가 하나씩 생기고, 이것을 행으로 쌓은 표가 야코비안 J예요. 03장의 「행렬 = 변환 기계」가 점마다 하나씩 붙는 셈이고, AI의 역전파는 이 표들을 차례로 곱하는 계산이에요.

m × n출력 m개, 입력 n개인 함수의 야코비안 모양
r극좌표 변환의 넓이 배율 det J
¼Δ를 반으로 줄이면 근사 오차는 약 4분의 1
4.5연쇄 예시 x = 0.5에서 dy/dx = 0.5 × 3 × 3

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 출력이 여러 개인 함수의 편미분을 행(출력)과 열(입력)로 늘어놓은 야코비안, 그것으로 하는 선형 근사, 그리고 기울기를 곱해 전달하는 연쇄 법칙을 배웁니다.
  2. 왜 중요한가: 신경망은 층마다 「입력 여러 개 → 출력 여러 개」인 함수예요. 역전파는 층마다의 야코비안을 출력 쪽부터 곱해 그래디언트를 구해요.
  3. 생활·현장에서는: 로봇 팔(관절 각도 → 손끝 위치), 카메라 렌즈 왜곡 보정, 극좌표 지도 바꾸기, 신경망 학습이 모두 야코비안을 써요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

영어 기호·약어 풀이 (펼치기)
  • J_F(x) — 함수 F의 점 x에서의 야코비안
  • ∂Fᵢ/∂xⱼ — i번째 출력을 j번째 입력으로 편미분 (i행 j열)
  • det J — 넓이(부피) 배율
  • Δx — 입력의 작은 변화

1단계 · 기울기 표 — 작은 원이 타원이 된다

방법: 야코비안 행렬일상: 로봇 팔의 손끝
박사

상황 질문 — 로봇 팔의 두 관절을 아주 조금씩 움직이면, 손끝은 어느 쪽으로 얼마나 움직일까요?

왜 이 방법을 쓰나

  1. 문제 상황: 입력 여러 개 → 출력 여러 개인 함수의 「기울기」를 한 번에 적고 싶어요.
  2. 앞 방법의 한계: 그래디언트는 출력이 하나일 때만 화살표 하나로 정리돼요.
  3. 해법: 출력마다의 그래디언트를 행으로 쌓아 표를 만들어요: i행 j열 = ∂(i번째 출력)/∂(j번째 입력). 이 표가 점 근처에서 함수가 하는 「늘이기·돌리기」를 알려 줘요.
쉽게 말하면 — 출력마다 그래디언트 한 줄씩, 쌓으면 야코비안.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

표의 행이 출력이에요, 입력이에요? 매번 헷갈려요.

학교 수학으로 보면: 03장 행렬과 08장 편미분의 조합이에요. 「행 = 출력, 열 = 입력」만 기억하면 돼요.

식 조각읽는 법뜻
F(x, y) = (u, v)출력 둘u = x + 0.3y², v = y − 0.3x²
J = [[∂u/∂x, ∂u/∂y], [∂v/∂x, ∂v/∂y]]야코비안1행 = u의 그래디언트, 2행 = v의 그래디언트
m × n모양출력 m개(행), 입력 n개(열)
숫자로 한 번 해 보기

∂u/∂x = 1, ∂u/∂y = 0.6y, ∂v/∂x = −0.6x, ∂v/∂y = 1

점 (1, 0.8): J = 1, 0.48], [−0.6, 1

det J = 1 × 1 − 0.48 × (−0.6) = 1.288 → 이 근처 넓이가 약 1.29배

1열 (1, −0.6)은 x를 조금 늘렸을 때 출력이 움직이는 화살표

조수 하루 (수강생)

그래디언트 두 개를 위아래로 쌓으니 03장의 행렬이 됐어요! 그래서 원이 타원이 되는구나.

일상으로 치면

로봇 팔 관절을 아주 조금 움직이면 손끝은 작은 타원 범위 안에서 움직여요. 어느 방향으로 잘 움직이는지가 그 타원 모양에 담겨요.

수학에서는

야코비안 J의 i행 j열 = ∂Fᵢ/∂xⱼ. 점 근처의 작은 원은 J에 따라 타원으로 바뀌고, 넓이 배율은 |det J|예요. 원자료 ①: 「Small circle in input space → Mapped to an ellipse in output space」.

박사

왼쪽 그림을 눌러 점을 옮기고, 초록 타원과 빨간 점선(J로 예측한 타원)을 비교해 보세요.

조수 하루

정말 원이 타원이 되네요. 그래디언트 하나로는 이 모양을 못 그려요.

초파리 연구원

「극좌표」를 골라 r을 키워 봐. 넓이 배율이 뭐랑 같아?

야코비안 실험 — 입력의 작은 원이 출력에서 타원으로

풀이 — 한 걸음씩

  1. 왼쪽은 입력 평면, 오른쪽은 출력 평면이에요. 모눈이 휘어 보이는 건 휘는 변환이라서예요.
  2. 작은 초록 원은 오른쪽에서 거의 타원이 돼요. 빨간 점선이 J로 예측한 타원이에요.
  3. 원을 작게 할수록 실제 모양과 예측이 딱 붙어요. 좁은 동네에서는 휘는 변환도 행렬처럼 행동해요.
  4. 극좌표 (r, θ) → (x, y)를 고르면 det J = r. 바깥쪽일수록 넓게 퍼져요(16장의 척도 인자).
이 단계의 한계 — 야코비안은 「그 점 근처」의 정보예요. 멀리 떨어진 점에서는 다른 J를 다시 계산해야 해요.
박사의 해석 — 야코비안은 「점마다 하나씩 붙은 행렬」이에요. 휘는 세상을 아주 작게 쪼개면 행렬(곧은 변환)의 모음으로 볼 수 있다는 것 — 이게 미분의 핵심 생각이에요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ①의 Jacobian: J_F(x) = [∂Fᵢ/∂xⱼ] (m × n), F: ℝⁿ → ℝᵐ, 작은 원 → 타원 그림.

2단계 · 선형 근사 — 조금 움직이면 표 하나로 예측

방법: F(x + Δx) ≈ F(x) + J·Δx일상: 내비게이션의 「잠시 후」 예측
박사

상황 질문 — 내비게이션은 지금 속도와 방향만으로 「10초 뒤 위치」를 꽤 정확히 예측해요. 1시간 뒤도 그렇게 예측할 수 있을까요?

왜 이 방법을 쓰나

  1. 문제 상황: 복잡한 함수의 출력을, 작은 변화에 대해서는 간단히 예측하고 싶어요.
  2. 앞 방법의 한계: 휘는 함수는 매번 계산하기 번거롭고, AI처럼 큰 함수는 계산이 비싸요.
  3. 해법: 지금 출력에 「야코비안 × 입력 변화」를 더해 예측해요. 변화가 작을수록 정확해요.
쉽게 말하면 — 조금 움직일 때는 「지금 값 + 기울기 표 × 움직임」.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

≈는 「거의 같다」인데, 얼마나 거의예요?

학교 수학으로 보면: 중학교 일차함수 y = (기울기)·x + b로 곡선을 짧게 흉내 내는 것과 같아요. 여기서는 기울기가 표(행렬)일 뿐이에요.

식 조각읽는 법뜻
F(x + Δx) ≈ F(x) + J·Δx선형 근사원자료 ①의 Jacobian 아래 식
J·Δx행렬 × 벡터03장 계산 그대로
오차실제 − 예측Δx를 반으로 줄이면 오차는 약 ¼
숫자로 한 번 해 보기

F = (x + 0.3y², y − 0.3x²), 점 (1, 0.8), F = (1.192, 0.5)

Δ = (0.3, 0.3): J·Δ = (0.3 + 0.48 × 0.3, −0.6 × 0.3 + 0.3) = (0.444, 0.12)

예측 (1.636, 0.62), 실제 F(1.3, 1.1) = (1.663, 0.593) → 차이 약 0.038

Δ = (0.15, 0.15)로 줄이면 차이 약 0.0095 — 약 ¼

조수 하루 (수강생)

걸음을 반으로 줄이면 오차가 4분의 1로 줄다니, 작게 움직일수록 표 하나로 충분하네요.

일상으로 치면

내비게이션은 「지금 속도 × 10초」로 바로 다음 위치를 잘 맞히지만, 1시간 뒤는 길이 굽어서 틀려요.

수학에서는

선형 근사 F(x + Δx) ≈ F(x) + J·Δx. 야코비안은 함수의 「가장 좋은 직선(평면) 흉내」예요. 작은 Δx일수록 정확해요.

Δ를 0.6까지 키워 봐. 차이가 어떻게 돼?

선형 근사 — 실제 출력과 J로 예측한 출력 비교

풀이 — 한 걸음씩

  1. 파란 화살표가 입력 변화 Δ, 오른쪽 초록이 실제 출력 변화, 빨간 점선이 J·Δ 예측이에요.
  2. Δ가 작으면 초록과 빨강이 거의 겹쳐요.
  3. Δ를 반으로 줄이면 차이가 약 4분의 1로 줄어요. 「곡선 정도」가 Δ의 제곱만큼 남기 때문이에요.
  4. 직선 변환(행렬)이었다면 차이는 언제나 0이에요.
이 단계의 한계 — 선형 근사는 크게 움직이면 틀려요. 그래서 경사 하강(10장)도 작은 걸음으로 가요 — 큰 걸음은 「기울기로 예측한 세상」 밖으로 나가 버려요.
박사의 해석 — 「작게 보면 직선」은 미분 전체를 꿰는 생각이에요. 그래디언트·야코비안·경사 하강 모두 이 근사를 믿고 작은 걸음만 써요.
원자료 인포그래픽 보기 (영어 그림)

3단계 · 연쇄 — 기울기는 곱해져 흐른다 (역전파)

방법: 연쇄 법칙과 역전파일상: 톱니바퀴 줄
박사

상황 질문 — 톱니바퀴 셋이 맞물려 있을 때, 첫 바퀴를 한 바퀴 돌리면 마지막 바퀴는 몇 바퀴 돌까요?

왜 이 방법을 쓰나

  1. 문제 상황: 여러 단계를 거치는 함수(신경망)의 기울기를 효율적으로 구하고 싶어요.
  2. 앞 방법의 한계: 전체 식을 한꺼번에 미분하면 길고 복잡해요. 층이 수십 개면 사실상 불가능해요.
  3. 해법: 단계마다의 국소 기울기(야코비안)를 구해 곱해요(연쇄 법칙). 출력 쪽부터 차례로 곱해 내려가는 것이 역전파예요.
쉽게 말하면 — 단계마다 「몇 배로 바뀌나」를 곱하면 전체가 몇 배로 바뀌나.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

곱하기만 하면 된다니, 정말요? 미분이 그렇게 단순해요?

학교 수학으로 보면: 고등학교 「합성함수의 미분」이에요. 바깥 기울기 × 안쪽 기울기.

식 조각읽는 법뜻
dy/dx = (dy/dv)·(dv/du)·(du/dx)연쇄 법칙단계마다의 기울기를 곱함
u = 3x, v = u², y = 0.5v + 1세 단계작은 「신경망」 예시
J_전체 = J₃·J₂·J₁여러 변수일 때야코비안(행렬)끼리 곱함
숫자로 한 번 해 보기

x = 0.5 → u = 1.5 → v = 2.25 → y = 2.125

국소 기울기: du/dx = 3, dv/du = 2u = 3, dy/dv = 0.5

곱: 0.5 × 3 × 3 = 4.5

검산: y = 4.5x² + 1을 바로 미분하면 9x = 4.5 ✓

조수 하루 (수강생)

톱니바퀴처럼 단계마다의 배율을 곱하면 되네요. 역전파가 이렇게 생긴 거였다니!

일상으로 치면

톱니바퀴 줄에서 첫 바퀴가 1바퀴 돌면, 다음 바퀴는 ×3, 그다음은 ×2… 배율을 차례로 곱하면 마지막 바퀴의 회전수가 나와요.

수학에서는

연쇄 법칙: 합성 함수의 기울기 = 단계별 기울기(야코비안)의 곱. 역전파는 이 곱을 출력 쪽부터 계산해 모든 가중치의 그래디언트를 한 번에 구해요.

박사

입력 x를 바꿔 가며 국소 기울기 세 개와 그 곱, 검산 값을 비교해 보세요.

주판봇

층이 세 개니까 기울기를 더하면 3 + 3 + 0.5 = 6.5!

초파리 연구원

검산 숫자를 봐. 더한 값이야, 곱한 값이야?

연쇄 계산기 — 층마다의 기울기를 곱해 전체 기울기 구하기

풀이 — 한 걸음씩

  1. 위쪽 줄은 입력 x가 세 층을 거쳐 출력 y가 되는 과정이에요.
  2. 국소 기울기 세 개(0.5, 2u, 3)를 곱하면 전체 기울기가 나와요.
  3. 검산 값(아주 조금 움직여 보기)과 곱한 값이 같아요.
  4. x = 0에서는 2u = 0이라 전체 기울기도 0 — 한 층이라도 기울기가 0이면 신호가 끊겨요.
이 단계의 한계 — 층이 아주 많으면 1보다 작은 기울기를 계속 곱해 0에 가까워지거나(기울기 소실), 1보다 큰 기울기를 곱해 폭발할 수 있어요. 실제 신경망 설계는 이 문제를 피하려고 많은 장치를 써요.
박사의 해석 — 역전파는 마법이 아니라 「국소 기울기 곱하기」예요. 층마다의 야코비안을 출력 쪽부터 곱해 내려가면 모든 가중치의 그래디언트를 한 번의 역방향 계산으로 얻어요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ① 아래쪽 Machine Learning: 「Backpropagation uses Jacobians to propagate derivatives.」 신경망 그림.

더 알고 싶은 분께 — 정확한 정의 (몰라도 됩니다)

층 함수 h₁ = f₁(x), h₂ = f₂(h₁), …, L = f_k(h_{k−1})에서 ∂L/∂x = J_{f₁}ᵀ J_{f₂}ᵀ … ∇L. 역전파는 오른쪽(∇L)부터 「벡터 × 야코비안」을 차례로 계산해 행렬끼리의 곱을 피한다(Rumelhart, Hinton & Williams, 1986).

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

하루가 AI에게 「F(x, y) = (x²y, x + y)의 점 (2, 1)에서 야코비안」을 물었더니 이렇게 답했어요.

AI 답변: 열마다 출력을 놓으면 J = [[∂u/∂x, ∂v/∂x], [∂u/∂y, ∂v/∂y]] = [[4, 1], [4, 1]]입니다.
