# 큐브 교실 — 루빅스 큐브로 배우는 군·탐색·AI

중학생도 따라올 수 있게 만든 루빅스 큐브 연구실 해설 시리즈예요. 인포그래픽 20장에 담긴 개념(상태 수, 돌리기 기호와 풀이법, CFOP·Roux·ZZ, 큐브 군, 켤레와 교환자, 풀 수 있는 세 조건, 부분군과 잉여류, 티슬스웨이트·코시엠바 알고리즘, 케일리 그래프, IDA*와 패턴 데이터베이스, 신의 수 20, 현대 AI 탐색)을 15장으로 나누고, 장마다 다른 수업 형식(1:1 토론, 조별 과제, 계산배틀, 발표수업, 찬반 토론, 쪽지시험 등)으로 풀었어요. 모든 장에 직접 돌려 볼 수 있는 큐브 시뮬레이터가 들어 있어요.

- 선생님: 박사 · 조교: 초파리 연구원, 주판봇 · 수강생: 인턴 시아, 인턴 모아, 조수 하루, 미공개 X1·X2·X3
- 1조 「꼭짓점조」 시아·하루·X1 / 2조 「모서리조」 모아·X2·X3

**바로 보기:** https://adminmrobo.github.io/ai_cube_lab/ (GitHub Pages를 켜면 열려요)

## 구성

- `index.html`, `NN_*.html`, `practice/index.html` — 페이지 (외부 라이브러리 없음, 글꼴만 외부 요청, 브라우저 저장소 사용 안 함)
- `assets/` — 공용 스타일(`lab.css`), 캐릭터·용어·퀴즈·대결(`lab.js`), 큐브 엔진과 실험(`widgets.js` ← `assets/src/c1~c4.js`), 실전 연습장(`practice.js`), 캐릭터 그림(`sprites.js`), 지식 색인·꾸러미(`js/kgx.js`)
- `content/` — 장별 내용 데이터, `tools/build.py` — 조립 스크립트 (`python3 tools/build.py --sprites <캐릭터 팩 sprites.js>`)
- `tools/cube_check.py` — 숫자 검산용 큐브 모형(파이썬), `tools/make_covers.py` — 픽셀아트 대체 표지 생성
- `img/source/` — 원자료 인포그래픽 20장(사용자 제공), `img/cover/`·`img/og/` — 표지와 공유 미리보기
- `docs/IMG_specs.md` — 표지·장면 그림 제작 명세서(16비트 RPG 픽셀아트 지시문), `docs/WORK_NOTES.md` — 사실 카드·원자료 바로잡기·검산·검증 기록
- `cover_manifest.json` — 표지·온톨로지 현황판 연결 파일

## 원자료와 다른 곳

원자료 인포그래픽에서 바로잡은 곳(신의 수 연대표의 연도·숫자·이름, 티슬스웨이트 보장 수 52/45, ELL 값, 스티커 번호 그림, 「다항식 증가」, 트랜스포머 주장 범위 등)은 각 단계의 「원자료 인포그래픽 보기」 상자와 `docs/WORK_NOTES.md`에 「원자료의 A를 이 페이지에서는 B로 바꿉니다」 형식으로 적었어요.
