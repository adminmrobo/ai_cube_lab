풀 수 있는 큐브의 세 조건

핵심 질문 — 조각을 마음대로 다시 끼운 큐브가 「돌려서 풀 수 있는 큐브」인지, 돌려 보지 않고 알 수 있을까?

01장에서 「마지막 꼭짓점의 방향은 저절로 정해진다」고 믿고 넘어갔어요. 오늘 그 이유를 밝혀요. 돌려서 풀 수 있는 큐브는 반드시 세 조건을 지켜요. ① 꼭짓점 비틀림의 합이 3의 배수 ② 뒤집힌 모서리 수가 짝수 ③ 꼭짓점과 모서리의 자리 바꿈 홀짝이 같음. 이것을 큐브 기본정리라고 불러요.

  2. 왜 중요한가: 01장의 「÷ 3, ÷ 2, ÷ 2」가 바로 이 세 조건이에요. 그리고 07장에서 「두 조각만 맞바꾸기는 불가능」이라고 한 이유가 조건 ③이에요.

1단계 · 비틀림의 합과 뒤집힘의 수 — 방향 조건 둘

방법: 불변량 (나머지)일상: 시계 바늘
박사

상황 질문 — 분해한 큐브의 꼭짓점 하나를 살짝 비틀어 끼웠어요. 이제 아무리 돌려도 풀 수 없다는 걸 어떻게 확신할까요?

30초 복습 — 나머지 연산
시계에서 10시 + 5시간 = 3시(15를 12로 나눈 나머지). 「3으로 나눈 나머지」는 0, 1, 2 중 하나로 돌고 돌아요.

왜 이 방법을 쓰나

  1. 문제 상황: 「영원히 안 된다」를 짧게 증명하고 싶어요.
  2. 앞 방법의 한계: 끝없이 돌려 보는 건 증명이 못 돼요.
  3. 해법: 돌릴 때마다 꼭짓점 비틀림의 합은 3의 배수만큼만, 뒤집힌 모서리 수는 짝수만큼만 바뀌어요. 그러니 「3으로 나눈 나머지」와 「홀짝」은 절대 안 바뀌어요(불변량).
쉽게 말하면 — 시계 바늘을 12시간씩만 돌릴 수 있다면, 3시 바늘은 영원히 3시예요.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

비틀림을 어떻게 숫자로 세요? 꼭짓점이 「얼마나」 비틀렸는지요?

학교 수학으로 보면: 중학교 「나머지」와 「짝수·홀수」: 비틀림을 0, 1, 2로 세고 합을 3으로 나눈 나머지를 봐요.

식 조각읽는 법뜻
cᵢ ∈ {0, 1, 2}꼭짓점 i의 비틀림흰·노란 스티커가 위아래를 보면 0, 시계 방향으로 한 번 비틀면 1, 두 번이면 2
Σcᵢ mod 3비틀림 합의 나머지돌려서 만든 큐브는 늘 0
eᵢ ∈ {0, 1}모서리 i의 뒤집힘바로 꽂힘 0, 뒤집힘 1
Σeᵢ mod 2뒤집힌 수의 홀짝돌려서 만든 큐브는 늘 짝수(0)
숫자로 한 번 해 보기

R 한 번: 꼭짓점 4개 비틀림이 +1, +2, +1, +2 → 합 +6 → 3으로 나눈 나머지 변화 0

F 한 번: 모서리 4개가 뒤집힘 → +4 → 짝수 유지

꼭짓점 하나만 비틀면 합 +1 → 나머지 1 → 영원히 못 풂

모서리 하나만 뒤집으면 홀수 → 영원히 못 풂

조수 하루 (수강생)

돌릴 때마다 바뀌긴 하는데 「3의 배수만큼」만 바뀌니까, 나머지는 절대 그대로구나!

일상으로 치면

시계 바늘을 「12시간씩」만 돌릴 수 있다면, 3시를 가리키던 바늘은 몇 번을 돌려도 3시예요. 12시로 만들 방법이 없어요.

큐브에서는

큐브를 돌리면 꼭짓점 비틀림의 합은 3의 배수만큼, 뒤집힌 모서리 수는 짝수만큼만 바뀌어요. 그래서 꼭짓점 하나를 비틀어 끼운 큐브(나머지 1)나 모서리 하나를 뒤집어 끼운 큐브(홀수)는 영원히 풀 수 없어요. 이런 값을 불변량이라 해요.

주판봇

많이 돌리면 언젠가는 비틀림이 풀리겠죠!

초파리 연구원

나머지 숫자를 봐. 20수를 몇 번 돌려도 1에서 안 움직여.

조립 검사기 — 손대고, 돌리고, 판정하기

풀이 — 한 걸음씩

  1. 꼭짓점 하나를 비틀면 조건 ①의 나머지가 1 또는 2가 돼요. 판정: 풀 수 없음.
  2. 이 상태에서 정상적으로 아무리 돌려도 나머지는 그대로예요. 돌리기는 3의 배수만큼만 바꾸니까요.
  3. 모서리 하나를 뒤집으면 조건 ②가 홀수가 돼요. 이것도 돌려서는 못 고쳐요.
  4. 꼭짓점 둘을 비틀되 하나는 +1, 하나는 +2로 하면 합이 3이라 다시 풀 수 있는 큐브가 돼요.
이 단계의 한계 — 이 검사기는 「스티커 색이 조각과 맞는 큐브」만 다뤄요. 스티커를 떼어 붙인 큐브는 조각 자체가 없는 색 조합이 생길 수 있어 다른 문제예요.
박사의 해석 — 「바뀌지 않는 값」 하나가 「영원히 불가능」을 증명해요. 무한한 시도 대신 짧은 계산 한 번 — 수학의 힘이에요.
원자료 인포그래픽 보기 (영어 그림)

원자료 「The Fundamental Theorem of Cubology」: Corner Orientation Constraint(합 mod 3 = 0), Edge Flip Constraint(뒤집힌 수 짝수).

원자료 제목의 「(Theorem 17)」은 특정 교재의 번호로 보여요. 이 페이지에서는 번호 없이 「큐브 기본정리」라고만 부릅니다.

2단계 · 자리 바꿈의 홀짝 — 두 조각만 맞바꿀 수 없는 이유

방법: 순열의 홀짝 (parity)일상: 카드 맞바꾸기
박사

상황 질문 — 모서리 두 개만 서로 자리를 바꿔 끼웠어요. 나머지는 완벽한데, 이 큐브는 풀 수 있을까요?

왜 이 방법을 쓰나

  1. 문제 상황: 「두 조각만 맞바꾸기」가 왜 불가능한지 알고 싶어요.
  2. 앞 방법의 한계: 07장 교환자로 3-순환은 만들었지만, 2개 맞바꾸기 식은 어디에도 없었어요.
  3. 해법: 면 하나를 90° 돌리면 꼭짓점 4개가 한 바퀴(맞바꿈 3번 = 홀수), 모서리 4개도 한 바퀴(3번 = 홀수). 늘 「같이」 홀짝이 바뀌니, 꼭짓점과 모서리의 홀짝은 늘 같아요.
쉽게 말하면 — 카드 두 줄을 늘 「함께」 한 번씩 섞으면, 두 줄의 섞임 횟수 홀짝은 늘 같아요.
일상으로 치면

카드 두 줄이 있는데, 한 번에 「두 줄을 함께」 한 번씩만 섞을 수 있다면, 한 줄만 몰래 한 번 더 섞은 상태는 절대 만들 수 없어요.

큐브에서는

면 하나를 돌리면 꼭짓점 순열과 모서리 순열이 「동시에」 홀짝이 바뀌어요. 그래서 둘의 홀짝은 늘 같아요. 모서리 두 개만 맞바꾼 큐브는 모서리만 홀짝이 바뀌어 영원히 풀 수 없어요. 반대로 꼭짓점 둘 + 모서리 둘을 함께 맞바꾸면 풀 수 있어요(PLL의 T-perm).

박사

「새 큐브」 → 「모서리 둘 맞바꾸기」, 그다음 「꼭짓점 둘 맞바꾸기」까지 눌러 보세요. 판정이 어떻게 바뀌죠?

주판봇

두 번 망가뜨렸으니 더 못 풀겠죠!

초파리 연구원

홀짝은 두 번 바뀌면 원래대로야. ③번 줄을 봐.

조립 검사기 — 맞바꾸기 실험

풀이 — 한 걸음씩

  1. 모서리 둘만 맞바꾸면 모서리 홀짝만 바뀌어 조건 ③ 실패.
  2. 이어서 꼭짓점 둘도 맞바꾸면 꼭짓점 홀짝도 바뀌어 둘이 다시 같아져요. 판정: 풀 수 있음!
  3. 그래서 PLL의 T-perm은 「꼭짓점 둘 + 모서리 둘」을 함께 맞바꿔요. 모서리 둘만 바꾸는 식은 없어요.
  4. 07장 교환자는 늘 「짝수 번 맞바꿈」이라 3-순환은 되지만 2개 맞바꾸기는 안 되는 것도 같은 이유예요.
이 단계의 한계 — 홀짝은 「몇 번 맞바꿨나」가 아니라 「짝수 번인가 홀수 번인가」만 알려 줘요. 같은 순열을 여러 방법으로 맞바꿈으로 나눌 수 있지만 홀짝은 늘 같아요.
박사의 해석 — 두 가지가 늘 함께 움직이는 세계에서는, 하나만 바꾸는 일은 불가능해요. 이 생각이 「검사 숫자」로 오류를 잡는 원리와 같아요.
원자료 인포그래픽 보기 (영어 그림)

원자료 첫째 상자 「Parity Constraint」: 꼭짓점 순열의 홀짝 = 모서리 순열의 홀짝.

더 알고 싶은 분께 — 정확한 정의 (몰라도 됩니다)

면 하나의 90° 회전은 꼭짓점과 모서리에 각각 4-순환을 일으키고, 4-순환은 홀순열이다. 따라서 sgn(σ_corner) = sgn(σ_edge)는 모든 움직임에서 보존된다. 세 조건을 모두 만족하는 배치가 실제로 모두 도달 가능하다는 것(충분성)은 교환자로 3-순환과 꼭짓점 쌍 비틀기·모서리 쌍 뒤집기를 만들어 보인다.

3단계 · 아무렇게나 조립하면 12번에 1번 — 1/12 실험

방법: 확률 실험과 곱셈 원리일상: 주사위·동전
박사

상황 질문 — 큐브를 완전히 분해해 아무렇게나 끼우면, 풀 수 있는 큐브가 될 확률은 얼마일까요?

왜 이 방법을 쓰나

  1. 문제 상황: 세 조건이 정말 「풀 수 있음」을 정확히 거르는지 숫자로 확인하고 싶어요.
  2. 앞 방법의 한계: 조건을 하나씩 확인했지만, 함께 걸렸을 때 얼마나 거르는지는 몰라요.
  3. 해법: 조건 ①은 1/3, ②는 1/2, ③은 1/2만 통과. 서로 독립이라 곱하면 1/12. 1,200번 무작위 조립으로 확인해요.
쉽게 말하면 — 주사위 하나(1/3 확률 사건) 굴리고 동전 둘 던져 모두 앞면이 나올 확률.
일상으로 치면

주사위를 굴려 1이나 2(확률 1/3), 동전 두 개가 모두 앞면(1/2 × 1/2)이 동시에 나올 확률은 1/3 × 1/2 × 1/2 = 1/12이에요.

큐브에서는

아무렇게나 조립한 큐브는 비틀림 조건을 1/3, 뒤집힘 조건을 1/2, 홀짝 조건을 1/2 확률로 통과해요. 셋 다 통과해야 풀 수 있으니 1/12. 01장의 「분해 조립 수 = 돌려서 만든 수 × 12」가 바로 이거예요.

초파리 연구원

셋 「다」 통과해야 해. 곱해야지, 더하면 안 돼.

조립 검사기 — 1,200번 무작위 조립 실험

풀이 — 한 걸음씩

  1. 무작위 조립: 꼭짓점 8개, 모서리 12개를 아무 자리에 아무 방향으로 끼워요.
  2. 조건 ①(비틀림)은 약 1/3, ②(뒤집힘)는 약 1/2, ③(홀짝)은 약 1/2이 통과해요.
  3. 세 조건이 서로 독립이라 함께 통과할 확률은 1/12 ≈ 8.3%. 실험값도 그 근처예요.
  4. 그래서 분해 조립 경우의 수 519,024,039,293,878,272,000 ÷ 12 = 43,252,003,274,489,856,000(01장).
이 단계의 한계 — 1,200번은 많지만 무한은 아니라 실험값은 8.3% 근처에서 조금씩 흔들려요. 「정확히 1/12」는 계산(곱셈 원리)이 보장해요.
박사의 해석 — 세 검사를 통과한 큐브만 풀이 프로그램에 넣어야 해요. 어긴 큐브를 넣으면 프로그램은 영원히 답을 찾으며 헤매요 — 입력 검사가 왜 중요한지 보여 줘요.
