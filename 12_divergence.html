발산 — 샘과 배수구 찾기

핵심 질문 — 화살표가 가득한 흐름 지도에서, 무언가가 「뿜어져 나오는 곳」과 「빨려 들어가는 곳」을 숫자로 찾을 수 있을까?

지금까지 화살표는 하나씩이었어요. 공간의 모든 점에 화살표가 하나씩 붙으면 벡터장(흐름)이 돼요. 바람 지도, 물 흐름, 사람들의 이동이 모두 벡터장이에요. 오늘은 그 흐름에서 샘(뿜어 나옴)과 배수구(빨려 들어감)를 재는 발산 ∇·v를 배워요. 원자료 ②의 둘째 상자예요.

2샘 흐름 (x, y)의 발산
−2배수구 흐름 (−x, −y)의 발산
0층층 흐름 (y, 0)의 발산 — 빨라도 0
∇·v발산 기호 — 나블라 점 브이

숫자 요약은 이 장의 예시 계산에서 나온 값입니다(실제 데이터가 아닌 설명용 값).

박사

기둥 4의 첫 시간이에요. 오늘부터 화살표는 「한 개」가 아니라 「온 공간에 가득」입니다.

인턴 모아

지구본조 주장: 물이 빠르게 흐르는 곳이 샘이에요! …아마도요.

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 공간의 점마다 화살표가 붙은 흐름(벡터장)을 보고, 작은 상자에서 나가는 양과 들어오는 양의 차이로 발산(샘과 배수구)을 재는 법을 배웁니다.
  2. 왜 중요한가: 발산은 「여기서 무언가가 생기나, 사라지나」를 알려 줘요. 물리(전기, 유체)의 핵심이고, 흐름을 이용하는 AI 생성 모델에서 「밀도가 어떻게 변하나」를 계산할 때도 써요.
  3. 생활·현장에서는: 수도꼭지 아래 물이 퍼지는 곳(샘), 세면대 배수구(빨려 들어감), 출근길 지하철역 출구의 인파, 열이 퍼져 나가는 난로가 모두 발산의 예예요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

영어 기호·약어 풀이 (펼치기)
  • v = (v₁, v₂) — 점마다 붙은 흐름 화살표 (벡터장)
  • ∇·v — 발산 — ∂v₁/∂x + ∂v₂/∂y (+ ∂v₃/∂z)
  • · — 점 곱 — 성분끼리 곱해 더하기
  • 선속 — 벽을 지나 나가는 양

미공개 X3

…상자 네 벽의 숫자를 다 더하면 되는 거죠?

인턴 시아

큐브조는 계산으로 보여 줄게요. 빠른 흐름도 들어온 만큼 나가면 0이에요.

왜 이 주제를 배우나

1흐름 전체를 한 번에 다루려고

바람·물·사람의 이동은 점마다 방향과 빠르기가 달라요. 벡터장으로 적어야 계산할 수 있어요.

2「생기는 곳」과 「사라지는 곳」을 찾으려고

수도꼭지, 배수구, 난로처럼 무언가가 나오거나 사라지는 곳은 발산이 0이 아니에요.

3델 연산자 가족을 완성하려고

∇f(09장)에 이어 ∇·v는 델 연산자의 둘째 쓰임이에요. 13장 회전, 15장 라플라시안으로 이어져요.

큰 그림 — 지금 어디쯤 있나

앞에서 배운 것02장 벡터, 08장 편미분, 09장 ∇
→
이번 장벡터장(흐름) → 발산 = 나감 − 들어옴 → 발산 0인 흐름
→
다음에 쓰는 곳13장 회전(∇×v), 15장 라플라시안(∇·∇f), 16장 원기둥·구면 좌표의 발산 공식
30초 복습 — 편미분
∂v₁/∂x는 y를 멈추고 x 방향으로만 잰 v₁의 변화율(08장). v₁ = 2x면 ∂v₁/∂x = 2.

그래디언트는 「높이」에서 화살표를 만들었고, 발산은 「화살표 밭」에서 숫자 하나를 만들어요. 방향이 거꾸로라는 것만 기억해 두세요.

1

1단계 · 흐름 지도와 샘·배수구

방법: 벡터장과 발산의 부호일상: 수도꼭지와 배수구
박사

상황 질문 — 세면대에 물을 틀고 마개를 뽑으면, 물이 퍼져 나가는 곳과 빨려 들어가는 곳이 생겨요. 화살표 지도에서 이 두 곳을 어떻게 알아볼까요?

왜 이 방법을 쓰나

  1. 문제 상황: 흐름 지도에서 「무언가가 생기는 곳/사라지는 곳」을 찾고 싶어요.
  2. 앞 방법의 한계: 화살표를 하나씩 보면 「모여드는지 퍼지는지」가 잘 안 보여요.
  3. 해법: 작은 상자를 놓고 「나가는 양 − 들어오는 양」을 재요. 양수면 샘, 음수면 배수구, 0이면 그냥 지나가는 흐름.
쉽게 말하면 — 상자에서 더 많이 나가면 샘, 더 많이 들어오면 배수구.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

화살표가 점마다 있다는 게 무슨 뜻이에요? 화살표가 무한히 많아요?

학교 수학으로 보면: 함수인데 출력이 숫자가 아니라 화살표예요. 11장의 「입력 여러 개 → 출력 여러 개」 함수와 같아요.

식 조각읽는 법뜻
v(x, y) = (x, y)샘 흐름중심에서 바깥으로 퍼짐
v(x, y) = (−x, −y)배수구 흐름중심으로 빨려 들어감
v = (1, 0.5)한결같은 바람어디서나 같은 화살표
숫자로 한 번 해 보기

샘: 점 (1, 0)의 화살표 (1, 0), 점 (2, 0)은 (2, 0) — 멀수록 빠르게 퍼짐

배수구: 점 (1, 0)은 (−1, 0) — 중심을 향함

한결같은 바람: 상자에 들어온 만큼 그대로 나감 → 발산 0

샘의 상자: 나감이 들어옴보다 많음 → 발산 양수

조수 하루 (수강생)

화살표 하나하나보다 「상자에서 나가고 들어오는 양」을 보니까 샘이 바로 보이네요.

일상으로 치면

수도꼭지 아래에서는 물이 사방으로 퍼져 나가고(샘), 배수구 주변에서는 사방에서 모여 빨려 들어가요(배수구).

수학에서는

벡터장 v는 점마다 화살표가 붙은 흐름이에요. 발산 ∇·v는 작은 상자에서 나가는 양 − 들어오는 양(넓이당)이에요. 양수 = 샘, 음수 = 배수구.

박사

흐름을 바꿔 가며 입자가 퍼지는지 모이는지, 상자 색이 어떻게 변하는지 보세요.

주판봇

한결같은 바람도 빠르게 흐르니 발산이 크겠죠!

초파리 연구원

한결같은 바람에서 상자 네 벽의 숫자를 다 더해 봐.

흐름 지도 ① — 샘, 배수구, 한결같은 바람

풀이 — 한 걸음씩

  1. 파란 점(입자)은 흐름을 따라 움직여요. 샘에서는 퍼지고, 배수구에서는 모여요.
  2. 상자가 빨갛게 변하면 발산 양수(샘), 파랗게 변하면 음수(배수구), 초록이면 0이에요.
  3. 샘 흐름 (x, y)는 어디에 상자를 놓아도 발산이 2예요. 「온 공간이 조금씩 뿜어 나오는」 흐름이에요.
  4. 한결같은 바람은 왼쪽 벽으로 들어온 만큼 오른쪽 벽으로 나가서 발산 0이에요.
이 단계의 한계 — 그림은 평면 흐름(성분 2개)이에요. 3차원 흐름은 위아래 벽까지 6개 벽을 재고, 공식에 ∂v₃/∂z가 더해져요.
박사의 해석 — 발산은 「그 자리가 무언가를 만들어 내는가, 삼키는가」를 숫자 하나로 알려 줘요. 화살표 밭 → 숫자 하나.
원자료 인포그래픽 보기 (영어 그림)

원자료 ②의 Divergence: ∇·v = ∂v_x/∂x + ∂v_y/∂y + ∂v_z/∂z. 가운데 빨간 공에서 화살표가 사방으로 뻗는 그림이 「샘」이에요.

2

2단계 · 발산 계산 — 상자 네 벽과 편미분 두 개

방법: ∇·v = ∂v₁/∂x + ∂v₂/∂y일상: 교실 문 네 개의 출입 인원
박사

상황 질문 — 쉬는 시간에 교실 문 네 개로 드나든 학생 수를 세면, 교실 안 학생이 늘었는지 줄었는지 알 수 있어요. 흐름에서도 같은 계산을 할 수 있을까요?

30초 복습 — 점 곱 (09장)
a·b = a₁·b₁ + a₂·b₂ — 성분끼리 곱해 더하기. ∇·v는 ∇ = (∂/∂x, ∂/∂y)의 「성분」과 v의 성분을 짝지어 「∂v₁/∂x + ∂v₂/∂y」로 읽는다는 표기 약속이에요.

왜 이 방법을 쓰나

  1. 문제 상황: 발산을 그림 없이 식으로 바로 계산하고 싶어요.
  2. 앞 방법의 한계: 상자 네 벽의 출입을 매번 재는 건 번거로워요.
  3. 해법: 상자를 아주 작게 하면, 좌우 벽의 차이는 ∂v₁/∂x, 위아래 벽의 차이는 ∂v₂/∂y가 돼요. 더하면 발산.
쉽게 말하면 — 좌우 출입 차 + 위아래 출입 차 = 편미분 두 개의 합.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

∇·v에서 점(·)은 곱하기예요? ∇랑 v를 어떻게 곱해요?

학교 수학으로 보면: 09장 방향 기울기의 「성분끼리 곱해 더하기」와 같은 모양이에요. ∇ = (∂/∂x, ∂/∂y)의 「성분」과 v의 성분을 짝지어요.

식 조각읽는 법뜻
∇·v = ∂v₁/∂x + ∂v₂/∂y발산좌우 변화 + 위아래 변화
∂v₁/∂x좌우 벽 차이오른쪽 벽에서 나감 − 왼쪽 벽에서 들어옴 (폭당)
∂v₂/∂y위아래 벽 차이위쪽 벽에서 나감 − 아래쪽 벽에서 들어옴 (높이당)
숫자로 한 번 해 보기

샘 v = (x, y): ∂x/∂x + ∂y/∂y = 1 + 1 = 2

배수구 v = (−x, −y): −1 + (−1) = −2

소용돌이 샘 v = (x − y, x + y): 1 + 1 = 2

층층 흐름 v = (y, 0): ∂y/∂x + ∂0/∂y = 0 + 0 = 0

조수 하루 (수강생)

편미분 두 개를 더하면 끝이네요. 상자 네 벽을 일일이 재지 않아도 되고요.

일상으로 치면

교실 문 네 개의 「나간 사람 − 들어온 사람」을 모두 더하면 교실 안 인원 변화를 알 수 있어요.

수학에서는

발산 ∇·v = ∂v₁/∂x + ∂v₂/∂y (3차원이면 + ∂v₃/∂z). 작은 상자의 출입 계산과 편미분 계산이 같은 값을 줘요.

박사

상자를 옮기고 크기를 바꿔 가며 「상자 계산」과 「공식 계산」을 비교해 보세요.

인턴 모아

흐름이 빙글빙글 도는 소용돌이 샘도 발산이 2예요?

초파리 연구원

층층 흐름을 골라 봐. 입자가 그렇게 빠른데 발산은?

흐름 지도 ② — 상자 출입 계산 vs 공식

풀이 — 한 걸음씩

  1. 아래 줄에 네 벽의 출입(음수 = 들어옴)과, 그 합 ÷ 넓이가 나와요.
  2. 그 아래 공식 ∂v₁/∂x + ∂v₂/∂y의 값과 같아요. 상자를 작게 할수록 더 정확히 맞아요.
  3. 소용돌이 샘은 돌면서 퍼지는 흐름 — 발산은 2, 도는 성분은 발산에 안 잡혀요(13장 회전에서 잡아요).
  4. 층층 흐름은 위쪽이 빠르고 아래쪽이 느리지만, 좌우로 들어온 만큼 나가서 발산 0이에요.
이 단계의 한계 — 상자 계산은 상자가 작을수록 공식과 가까워져요. 흐름이 급하게 바뀌는 곳에서 큰 상자를 쓰면 값이 달라요.
박사의 해석 — 발산 공식은 「좌우 변화 + 위아래 변화」예요. 그래디언트(∇f)는 편미분을 「나란히 늘어놓고」, 발산(∇·v)은 편미분을 「더해서 숫자 하나로」 만들어요.
∇·v의 점이 낯설면 「편미분 두 개를 더한다」로만 읽어도 충분해요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ③ 큐브 기둥의 Divergence: ∇·v = ∂v_x/∂x + ∂v_y/∂y + ∂v_z/∂z. 원기둥·구면 기둥의 식이 복잡한 이유는 16장에서.

방법: 발산 없는 흐름일상: 꽉 찬 지하철 통로
박사

상황 질문 — 꽉 찬 지하철 통로에서는 한 사람이 들어오면 한 사람이 밀려 나가요. 이런 흐름은 어디서나 무엇이 성립할까요?

왜 이 방법을 쓰나

  1. 문제 상황: 「어디서도 생기거나 사라지지 않는 흐름」을 알아보고 싶어요.
  2. 앞 방법의 한계: 빠르기나 휘어짐만 보면 이런 흐름을 구별하기 어려워요.
  3. 해법: 모든 점에서 발산이 0인지 확인해요. 물처럼 압축되지 않는 흐름은 발산이 0이에요.
쉽게 말하면 — 어디에 상자를 놓아도 들어온 만큼 나간다.

학교 수학으로 보면: 편미분 두 개의 합이 0인지만 보면 돼요. 움직임의 크기와는 상관없어요.

흐름 지도 ③ — 발산이 어디서나 0인 흐름 찾기

풀이 — 한 걸음씩

  1. 소용돌이, 층층 흐름, 한결같은 바람은 상자를 어디에 놓아도 발산 0(초록)이에요.
  2. 샘만 어디서나 2(빨강)예요.
  3. 발산 0인 흐름의 입자들은 모이거나 흩어지지 않고, 서로 간격을 유지한 채 움직여요.
  4. 「많이 움직인다」와 「뿜어 나온다」는 서로 다른 성질이에요. 오늘 토론의 결론이에요.
이 단계의 한계 — 현실의 공기는 조금씩 압축되고, 사람 흐름도 출입구에서는 발산이 생겨요. 「발산 0」은 단순하게 본 모형이에요.
박사의 해석 — AI의 「흐름 기반 생성 모델」은 데이터를 흐름으로 옮길 때 발산으로 「밀도가 어떻게 바뀌는지」를 계산해요. 발산 0이면 밀도가 그대로, 양수면 묽어져요.
