헤시안 — 휨을 적은 표

핵심 질문 — 기울기가 0인 평평한 점이 바닥인지, 꼭대기인지, 안장인지 숫자로 가릴 수 있을까?

07장에서 「기울기 0 ≠ 바닥」이라는 함정을 봤어요. 그걸 가려내는 도구가 「기울기의 기울기」, 즉 2차 미분이에요. 입력이 여러 개면 2차 편미분을 표로 늘어놓은 헤시안 H가 되고, 이 표의 부호가 그릇·돔·안장을 알려 줘요. 원자료 ①의 셋째 기둥이에요.

  2. 왜 중요한가: AI 학습에서 손실 지형의 휨은 학습률의 한계(10장)와 안장점 문제(07장)를 결정해요. 뉴턴 방법 같은 2차 방법은 헤시안으로 더 똑똑한 걸음을 골라요.
  3. 생활·현장에서는: 자동차가 커브에서 얼마나 휘는지(곡률), 다리의 처짐, 손실 지형의 바닥 판정, 사진에서 얼룩(점 모양) 찾기에 2차 미분과 헤시안이 쓰여요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

1단계 · 기울기의 기울기 — 위로 휨, 아래로 휨

방법: 2차 미분일상: 미끄럼틀과 그네
박사

상황 질문 — 그네는 가운데가 가장 낮고 양쪽으로 갈수록 가팔라져요. 미끄럼틀 꼭대기는 반대예요. 이 차이를 숫자로 나타내려면?

왜 이 방법을 쓰나

  1. 문제 상황: 곡선이 그릇처럼 휘었는지, 돔처럼 휘었는지 알고 싶어요.
  2. 앞 방법의 한계: 기울기(1차 미분)는 「지금 얼마나 가파른가」만 알려 줘요. 기울기 0인 점에서는 아무 정보가 없어요.
  3. 해법: 기울기가 어떻게 변하는지(기울기의 기울기 = 2차 미분 f″)를 재요. 양수면 위로 휨(그릇), 음수면 아래로 휨(돔).
쉽게 말하면 — 기울기가 커지고 있으면 그릇, 작아지고 있으면 돔.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

미분을 두 번 하면 뭐가 남아요? 또 미분해도 돼요?

학교 수학으로 보면: 고등학교 「이계도함수」예요. 미분 결과도 함수라서 한 번 더 미분할 수 있어요.

식 조각읽는 법뜻
f″(x)에프 투 프라임기울기 f′의 기울기
f″ > 0위로 휨 (∪)그릇 — 기울기 0이면 바닥
f″ < 0아래로 휨 (∩)돔 — 기울기 0이면 꼭대기
숫자로 한 번 해 보기

f = x²: f′ = 2x, f″ = 2 > 0 → 어디서나 그릇

f = −x²: f″ = −2 < 0 → 어디서나 돔

f = x³: f′ = 3x², f″ = 6x → x > 0이면 그릇, x < 0이면 돔

x³의 x = 0: f′ = 0, f″ = 0 → 바닥도 꼭대기도 아님(휨이 바뀌는 곳)

조수 하루 (수강생)

기울기만 보면 0인 점들이 다 똑같아 보였는데, 휨까지 보니 정체가 드러나네요.

일상으로 치면

그네는 가운데에서 멀어질수록 점점 가팔라지고(기울기가 커짐), 미끄럼틀 꼭대기는 내려갈수록 가팔라져요(기울기가 작아짐 = 음수로 커짐).

수학에서는

2차 미분 f″ > 0이면 위로 휨(∪), f″ < 0이면 아래로 휨(∩). 기울기 0인 점에서 f″ > 0이면 바닥, f″ < 0이면 꼭대기.

인턴 시아

(발표) 빨강은 위로 휨, 파랑은 아래로 휨이에요. y = x³을 보세요.

주판봇

기울기가 0인 x³의 원점은 바닥이죠!

초파리 연구원

원점 양옆의 색을 봐. 하나는 빨강, 하나는 파랑이야.

휨 색칠 — 2차 미분의 부호

풀이 — 한 걸음씩

  1. 곡선 색이 빨강이면 위로 휨(f″ > 0), 파랑이면 아래로 휨(f″ < 0)이에요.
  2. y = x²은 온통 빨강 — 어디서나 그릇이고 원점이 바닥이에요.
  3. y = x³은 원점을 기준으로 색이 바뀌어요. 원점은 기울기 0이지만 바닥이 아니에요.
  4. 점선은 그 점의 접선이에요. 그릇 쪽에서는 곡선이 접선 위에, 돔 쪽에서는 아래에 있어요.
이 단계의 한계 — f″ = 0인 점은 이 방법으로 판정이 안 돼요(x³, 원숭이 안장). 더 높은 차수의 미분을 봐야 하지만 여기서는 다루지 않아요.
박사의 해석 — 휨은 「바닥 판정」과 「얼마나 빨리 가팔라지나」를 함께 알려 줘요. 손실 지형이 많이 휜 방향일수록 학습률을 작게 잡아야 해요(10장).

2단계 · 헤시안 — 2차 편미분의 대칭 표

방법: 헤시안 행렬과 판정일상: 그릇·돔·안장 감별
박사

상황 질문 — 눈을 가리고 손으로 곡면 가운데를 만져 그릇인지, 돔인지, 말안장인지 알아맞히려면 무엇을 느껴야 할까요?

30초 복습 — 고유값 맛보기
대각선 행렬 3, 0], [0, 1은 x 방향으로 3배, y 방향으로 1배 늘이는 기계예요(03장). 이렇게 「방향은 그대로 두고 길이만 바꾸는 방향」의 배율이 고유값이고, 여기서는 3과 1이에요. 헤시안에서는 그 배율이 「그 방향의 휨」이에요.

왜 이 방법을 쓰나

  1. 문제 상황: 입력이 여러 개인 함수에서 휨을 한꺼번에 적고 판정하고 싶어요.
  2. 앞 방법의 한계: 방향마다 휨이 달라요(말안장은 한쪽은 ∪, 다른 쪽은 ∩). 2차 미분 하나로는 부족해요.
  3. 해법: 2차 편미분을 모두 모아 표로 만들어요: H = ∂²f/∂x², ∂²f/∂x∂y], [∂²f/∂y∂x, ∂²f/∂y². 대칭 표이고, 판정값 det H = ac − b²와 a의 부호로 모양을 가려요.
쉽게 말하면 — 방향마다의 휨을 표 하나에.

조수 하루 (수강생)

표 안에 ∂²이 네 개나 있어요. 다 다르게 계산해야 해요?

학교 수학으로 보면: 08장 편미분을 두 번씩 하는 거예요. 섞인 두 개(오른쪽 위, 왼쪽 아래)는 매끄러운 함수라면 같아서, 실제로 계산할 건 세 개예요.

식 조각읽는 법뜻
H = [[a, b], [b, c]]2변수 헤시안a = ∂²f/∂x², b = ∂²f/∂x∂y, c = ∂²f/∂y²
det H = ac − b²판정값> 0이고 a > 0: 그릇 / > 0이고 a < 0: 돔 / < 0: 안장
λ₁, λ₂고유값가장 많이·적게 휘는 방향의 휨. 둘 다 +면 그릇, 둘 다 −면 돔, 부호가 다르면 안장
숫자로 한 번 해 보기

f = x² + 2y² (그릇): a = 2, b = 0, c = 4 → det = 8 > 0, a > 0 → 그릇

f = y² − x² (말안장): a = −2, b = 0, c = 2 → det = −4 < 0 → 안장

f = x² + 3xy + y²: a = 2, b = 3, c = 2 → det = 4 − 9 = −5 < 0 → 안장!

마지막은 대각선이 모두 양수인데도 안장 — 섞인 항 b가 커서

대각선만 보면 그릇 같은데 b 때문에 안장이 되다니! 표 전체를 봐야 하는구나.

일상으로 치면

곡면 가운데를 손으로 만지며 앞뒤·좌우·대각선 방향으로 휨을 느끼면 그릇·돔·안장을 알 수 있어요. 헤시안은 그 「손끝 감각」을 숫자 표로 적은 것이에요.

수학에서는

헤시안 H의 i행 j열 = ∂²f/∂xᵢ∂xⱼ. 매끄러운 함수에서는 대칭이에요. 판정: 고유값이 모두 양수면 극소(그릇), 모두 음수면 극대(돔), 섞이면 안장. 원자료 ①: 「Its eigenvalues describe local curvature and help classify critical points.」

초파리 연구원

a = 2, c = 2로 두고 b만 3까지 올려 봐.

헤시안 실험 — a, b, c로 그릇·돔·말안장 만들기

풀이 — 한 걸음씩

  1. f = ½(ax² + 2bxy + cy²)이면 헤시안이 정확히 a, b], [b, c예요. 대각선 기준으로 대칭이에요.
  2. a, c > 0이고 b = 0이면 그릇이에요. 등고선은 타원.
  3. b를 키우면 그릇이 비스듬히 찌그러지다가, b² > ac가 되는 순간 말안장으로 바뀌어요. 등고선이 쌍곡선이 돼요.
  4. 고유값 λ₁, λ₂는 「가장 많이 휘는 방향의 휨」과 「가장 적게 휘는 방향의 휨」이에요.
이 단계의 한계 — 판정값이 0이면(어느 방향이 평평하면) 헤시안만으로 판정할 수 없어요. 원숭이 안장(07장)의 가운데가 그런 예예요.
박사의 해석 — 헤시안은 그래디언트의 야코비안이에요(「기울기 화살표가 어떻게 변하나」의 표). 원자료 ①: 「Captures how the gradient changes.」
고유값이 처음이라면 「표의 부호 판정」(ac − b²와 a)만 가져가도 충분해요. 고유값은 같은 판정을 더 많은 변수로 늘리는 방법이에요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ①의 Hessian: H_f(x) = [∂²f/∂xᵢ∂xⱼ] (n × n), symmetric, 말안장 그림.

원자료는 헤시안을 그냥 「(symmetric)」이라고 적었지만, 대칭이 되려면 2차 편미분이 연속인 매끄러운 함수여야 해요(대부분의 AI 손실 함수는 이 조건을 만족해요). 이 페이지에서는 「매끄러운 함수에서는 대칭」이라고 조건을 붙입니다.

3단계 · 뉴턴 방법 — 휨을 알면 걸음이 똑똑해진다

방법: 뉴턴 방법 (2차 최적화)일상: 그릇 바닥 한 번에 짚기
박사

상황 질문 — 그릇 모양을 정확히 안다면, 바닥까지 몇 걸음 걸어야 할지 미리 알 수 있지 않을까요?

왜 이 방법을 쓰나

  1. 문제 상황: 경사 하강보다 적은 걸음으로 바닥에 가고 싶어요.
  2. 앞 방법의 한계: 경사 하강은 기울기만 보고 정해진 η로 걸어서, 걸음이 너무 작거나 크기 쉬워요(10장).
  3. 해법: 기울기를 휨으로 나눈 만큼 걸어요: x ← x − f′(x) / f″(x). 여러 변수면 x ← x − H⁻¹∇f. 그릇(2차식)이면 한 걸음에 바닥이에요.
쉽게 말하면 — 많이 휘었으면 조금, 완만하면 멀리.

조수 하루 (수강생)

왜 기울기를 휨으로 나누면 바닥까지 거리가 돼요?

학교 수학으로 보면: 중학교 3학년 이차함수의 꼭짓점 공식과 같아요. y = a(x − p)² + q에서 꼭짓점까지의 거리는 기울기 ÷ (2a)이고, 2a가 바로 휨 f″예요.

식 조각읽는 법뜻
x ← x − f′(x) / f″(x)뉴턴 걸음 (1변수)기울기 ÷ 휨만큼 이동
x ← x − H⁻¹∇f뉴턴 걸음 (여러 변수)H⁻¹(역행렬)은 「헤시안으로 나누기」를 행렬로 한 것 — 1변수의 ÷ f″와 같은 뜻. 예: 2, 0], [0, 4의 역행렬은 1/2, 0], [0, 1/4
f″가 작을 때주의거의 평평한 곳에서는 걸음이 엄청 커질 수 있음
숫자로 한 번 해 보기

f = (x − 2)² + 1, 출발 x = −1: f′ = −6, f″ = 2

뉴턴: x = −1 − (−6) / 2 = 2 → 한 걸음에 바닥

경사 하강(η = 0.1): x = −1 + 0.6 = −0.4, 거리가 걸음마다 0.8배 — 바닥(0.01 이내)까지 약 26걸음

f = x⁴/4 − x + 1, 출발 −1: 뉴턴 −0.33 → 2.78 → 1.90 → 1.36 → … → 1 (한 번 크게 튐)

조수 하루 (수강생)

휨으로 나누면 「얼마나 가야 하는지」가 나오는구나. 대신 휨이 작은 곳에서는 조심해야 하고요.

일상으로 치면

그릇 모양을 손으로 정확히 느끼면, 지금 자리에서 바닥까지 한 번에 손을 뻗어 짚을 수 있어요.

수학에서는

뉴턴 방법은 기울기를 휨(헤시안)으로 나눠 걸음을 정해요. 2차식이면 한 걸음, 바닥 근처에서는 아주 빠르게 수렴해요. 대신 헤시안 계산이 비싸고, 휨이 작거나 안장 근처면 엉뚱하게 튈 수 있어요.

뉴턴 방법이 한 걸음이면, 이제 AI는 모두 뉴턴 방법으로 학습하겠네요!

초파리 연구원

4차 함수로 바꿔서 눌러 봐. 첫 걸음들이 어디로 가는지.

걸음 비교 — 경사 하강 vs 뉴턴 방법

풀이 — 한 걸음씩

  1. 그릇 모양 (x − 2)² + 1에서 뉴턴은 한 걸음에 x = 2(바닥)예요. 경사 하강은 수십 걸음 걸려요.
  2. 4차 함수에서 뉴턴은 휨이 작은 x = 0 근처를 지날 때 2.78까지 크게 튀었다가 돌아와요.
  3. 바닥 근처에 오면 뉴턴은 매우 빨라요(걸음마다 맞는 자릿수가 거의 두 배).
  4. 실제 AI는 가중치가 수백만 개라 헤시안(수백만 × 수백만 표)을 다 계산하기 어려워요. 그래서 흉내 낸 방법을 써요.
이 단계의 한계 — 헤시안은 변수가 n개면 n × n개의 숫자가 필요해요. 변수가 백만 개면 1조 개 — 그래서 대부분의 AI는 경사 하강 계열을 쓰고, 헤시안은 일부만 근사해서 써요.
박사의 해석 — 경사 하강은 「기울기만 보는 걸음」, 뉴턴 방법은 「기울기와 휨을 함께 보는 걸음」이에요. 원자료 ①: 「Newton’s method uses the Hessian to find better steps.」
원자료 인포그래픽 보기 (영어 그림)

원자료 ① 아래쪽 Second-order Methods: 「Newton’s method uses the Hessian to find better steps and analyze local minima and maxima.」

더 알고 싶은 분께 — 정확한 정의 (몰라도 됩니다)

다변수 뉴턴 걸음: x ← x − H(x)⁻¹∇f(x). 2차 테일러 근사 f(x + Δ) ≈ f(x) + ∇fᵀΔ + ½ΔᵀHΔ를 최소로 하는 Δ = −H⁻¹∇f에서 나온다. H가 양의 정부호가 아니면(안장 근처) 이 걸음이 오르막일 수 있어 보정이 필요하다(Nocedal & Wright, 2006).

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

하루가 AI에게 「손실 함수의 기울기가 0인 점에서 헤시안이 2, 3], [3, 2예요. 여기가 최솟값인가요?」라고 물었어요.

AI 답변: 헤시안의 대각선 성분이 모두 양수(2, 2)이므로 위로 휘어 있고, 따라서 이 점은 최솟값입니다.
