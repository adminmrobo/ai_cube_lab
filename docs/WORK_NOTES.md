# 작업 메모 — 큐브 교실 (ai_cube_lab)

- 독자 진단: 주 독자를 「수학이 어렵고 행렬·벡터를 처음 배우는 학생(중학생 눈높이)」으로 받음 → **혼합형**으로 가정(수식 막힘 처방 먼저, 해석 연습은 뒤에).
- 원자료: 사용자가 준 인포그래픽 20장 (`img/source/src01~20.webp`, 받은 순서대로 번호). 출처 미상 — 꾸러미에서 "확인 필요".
- 원자료와 다른 값은 기본값대로 "원자료의 A를 이 페이지에서는 B로 바꿉니다"로 표기.
- 분야: 수학(군론·그래프) 주 분야, 인공지능(탐색·신경망) 보조. 비유 앵커는 D(일상).
- 용어 규칙: 개념정리·단계·항목·공란·상자만 사용. 금지 표현(오르내리는 기구 비유, 뚫고 지나간다는 말, 구획 단위어)과 독자를 낮춰 부르는 별칭은 0건.

## 검산한 숫자 (tools/cube_check.py, 브라우저 엔진 양쪽)
- 상태 수 8!·3⁷·12!·2¹¹/2 = 43,252,003,274,489,856,000, 분해 조립 ×12 = 519,024,039,293,878,272,000.
- 차수: R 4, R U 105, R U R′ U′ 6, 수네 6, F R U R′ U′ F′ 6.
- [R U R′, D]와 [R U R′, D2]: 스티커 9장(꼭짓점 3개) 이동, 차수 3. 슈퍼플립 20수 식: 스티커 24장(모서리 12개 뒤집힘), 차수 2.
- 층 크기(HTM): 1, 18, 243, 3,240, 43,239 (BFS 직접 계산). 3수 이하 합 3,502.
- 티슬스웨이트 잉여류 곱 2,048 × 1,082,565 × 29,400 × 663,552 = |G|. 1,082,565 = 3⁷ × 495.
- 코시엠바: |H| = 8!·8!·4!/2 = 19,508,428,800, |G|/|H| = 2,217,093,120 = 2¹¹·3⁷·495.
- 코르프 표: 8!·3⁷ = 88,179,840, 12!/6!·2⁶ = 42,577,920.
- 무작위 조립 12,000번 중 풀 수 있는 비율 8.8%(이론 1/12 = 8.3%).
- 작은 무리 지름: 시계(+1) 11, (+1, +5) 5, (+1, +5, −1) 4 / 정사각형(돌리기+뒤집기) 3 / 카드 4장(앞 두 장 바꾸기 + 밀기) 6, 세 가지 모두 4.
- 탐색 예: 5수 섞기 U B2 R2 F R — 그냥 깊이 우선 2,477,493개, IDA*(쌍 패턴 표 10개) 255개.
- 부분 목표 퍼즐(+1, ×2): 1,000까지 직접 545개, 부분 목표 18개(약 30배).
