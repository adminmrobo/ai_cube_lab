# 작업 메모 — 큐브 교실 (ai_cube_lab)

- 독자 진단: **혼합형**으로 가정 (수식 막힘 처방 먼저, 해석 연습은 뒤에). 주 독자 한 줄: 행렬·벡터를 처음 배우는 중학생, 미분은 처음 보는 학생.
- 원자료: 사용자가 준 인포그래픽 4장 (`img/source/src01~04.webp`). 작성자 미상 — 꾸러미에서 「확인 필요」.
  - ① Gradient, Jacobian and Hessian ② The Del Operator ③ Vector Derivatives — Same operators, different coordinates ④ 3차원 곡면 11종 도감
- 원자료와 다른 값은 기본값대로 「원자료의 A를 이 페이지에서는 B로 바꿉니다」로 표기.
- 분야: 수학(벡터 미적분·선형대수) 주 분야, 인공지능(학습·역전파·이미지 처리) 보조. 비유 앵커는 일상.
- 스킬: ai-lab-explainer-plain (교수법 P1~P7 내장). 흰 배경, 캐릭터 팩 재사용(`assets/sprites.js`는 topology_ai_lab과 같은 96px 팩).

## 역할 (사용자 지정)
| 자리 | 캐릭터 |
|---|---|
| 선생님 | 박사 |
| 조교 | 초파리 연구원(의심 담당), 주판봇(확신 담당) |
| 수강생 | 인턴 시아(인턴1), 인턴 모아(인턴2), 조수 하루, 미공개 X1·X2·X3 |
| 1조 「큐브조」 | 시아 · 하루 · X1 |
| 2조 「지구본조」 | 모아 · X2 · X3 |

조 이름은 원자료 ③ 공식표의 첫 기둥(큐브 = 직교 좌표)과 마지막 기둥(지구본 = 구면 좌표)에서 따왔다.

## 장 나누기 — 「독자가 이해하기 쉬운 규모」 기준
- 원칙: 한 장 = 새 기호 묶음 하나 + 개념 2~4단계, 20~30분. 앞 장의 한계가 다음 장의 이유가 되게 잇는다.
- 행렬·벡터가 처음인 독자를 위해 원자료에 없는 바탕 장 3개(01 좌표, 02 벡터, 03 행렬)와 미분 복습(08장 1단계)을 앞에 두었다.
- 곡면 11종은 한 장에 몰지 않고 「바닥이 하나인 가족(06)」과 「부호가 바뀐 가족 + 이차곡면 밖(07)」으로 나눴다.
- 어려운 단계는 「심화」로 접음: 11장 3단계(역전파), 14장 3단계(뉴턴 방법), 16장 3단계(곡선 좌표 공식). 심화 과정 장: 11·14·16.

| F2 (①) | 헤시안 「(symmetric)」 | 「2차 편미분이 연속인 매끄러운 함수에서는 대칭」으로 조건을 붙임 | 클레로 정리 (Stewart 14.3) |
