구면 좌표 — 지구본의 주소

핵심 질문 — 공 모양 위의 점을, 위도·경도처럼 부르려면 숫자를 어떻게 정할까?

지구 위의 도시는 「위도·경도」로 불러요. 여기에 중심에서의 거리를 더하면 공 모양 어디든 부를 수 있는 구면 좌표 (r, θ, φ)가 돼요. 원자료 공식표의 셋째 기둥 「Spherical」이에요.

(r, θ, φ)구면 주소의 세 숫자
θ = 0°북극 (원자료 약속: 북극에서 잰 각)
r·sin θ바닥 그림자까지의 거리 = 원기둥의 s
r = 2반지름 2인 공 껍질의 식

숫자 요약은 이 장의 예시 계산에서 나온 값입니다(실제 데이터가 아닌 설명용 값).

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 중심에서 거리 r, 북극에서 내려온 각 θ, 가로로 돈 각 φ로 점을 부르는 구면 좌표와 큐브 주소로 바꾸는 공식을 배웁니다.
  2. 왜 중요한가: 공 모양, 빛·소리처럼 한 점에서 사방으로 퍼지는 것은 구면 주소로 다루면 식이 아주 짧아요. 16장 공식표의 셋째 기둥이에요.
  3. 생활·현장에서는: GPS의 위도·경도, 3D 카메라의 「위아래·좌우로 돌리기」, 드론 카메라 각도, 스피커 소리의 퍼짐이 구면 주소예요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

영어 기호·약어 풀이 (펼치기)
  • r — 중심에서의 직선 거리
  • θ — 세타. 북극(+z축)에서 아래로 내려온 각 (0° ~ 180°)
  • φ — 파이. 가로로 돈 각 — 경도와 같은 역할 (0° ~ 360°)
  • r̂, θ̂, φ̂ — 바깥쪽, 남쪽, 동쪽 방향의 단위 벡터

왜 이 주제를 배우나

1공 모양을 자연스럽게 부르려고

지구, 공, 빛이 퍼지는 모양은 「중심에서 얼마나, 어느 방향」이 먼저 떠올라요.

2식을 짧게 만들려고

반지름 2인 공 껍질이 큐브로는 x² + y² + z² = 4, 구면 주소로는 r = 2예요.

3방향과 크기를 나누어 보려고

구면 주소는 「크기(r)」와 「방향(θ, φ)」을 나눠 적어요. AI가 단어 벡터의 방향으로 뜻을 비교하는 것과 같은 생각이에요.

큰 그림 — 지금 어디쯤 있나

30초 복습 — 삼각비 복습
빗변 r, 각 θ인 직각삼각형: 이웃 변 = r·cos θ, 마주 보는 변 = r·sin θ. cos 90° = 0, sin 90° = 1.

θ와 φ는 둘 다 각도라 헷갈리기 쉬워요. θ는 「위아래」, φ는 「가로로 돌기」라고만 기억하면 충분해요.

1

1단계 · 지구본 주소 — (r, θ, φ)

방법: 구면 좌표일상: 위도와 경도
박사

상황 질문 — 친구가 사는 도시를 지구본에서 찾으려면, 어떤 숫자 두 개가 필요할까요? 우주 정거장이라면 하나가 더 필요해요.

왜 이 방법을 쓰나

  1. 문제 상황: 공 모양 공간의 자리를 위도·경도처럼 부르고 싶어요.
  2. 앞 방법의 한계: 큐브 주소로는 「지구 표면 위」라는 조건이 x² + y² + z² = 반지름²이라는 복잡한 식이 돼요.
  3. 해법: 중심에서의 거리 r, 북극에서 내려온 각 θ, 가로로 돈 각 φ를 주소로 써요.
쉽게 말하면 — 「중심에서 얼마나, 북극에서 몇 도 내려와서, 가로로 몇 도 돌아서」.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

위도는 적도가 0°인데, θ는 북극이 0°라고요? 헷갈려요.

학교 수학으로 보면: 중학교 사회 「위도와 경도」에 「중심에서의 거리」를 더한 거예요. θ = 90° − 위도예요.

식 조각읽는 법뜻
r알중심에서의 직선 거리 (0 이상)
θ세타북극에서 내려온 각. 0°=북극, 90°=적도, 180°=남극
φ파이가로로 돈 각 (경도 역할). 04장의 φ와 같음
숫자로 한 번 해 보기

서울 근처: 북위 약 37.5° → θ = 90° − 37.5° = 52.5°

적도 위의 점: θ = 90°

북극: θ = 0° — φ를 바꿔도 같은 점

(r, θ, φ) = (1, 90°, 0°)는 적도 위, x축 방향의 점

조수 하루 (수강생)

θ는 「북극에서 몇 도」, 위도는 「적도에서 몇 도」라서 더하면 90°구나. 출발선만 다르네요.

일상으로 치면

지구본에서 도시는 위도·경도 두 숫자로 찾고, 우주 정거장은 「지면에서 높이」까지 세 숫자가 필요해요.

수학에서는

구면 좌표 (r, θ, φ): 중심 거리 r, 북극에서 내려온 각 θ, 가로 각 φ. 원자료 ③의 오른쪽 기둥이에요.

인턴 모아

세 손잡이를 하나씩 돌려 보세요. r은 풍선 크기, θ는 위아래, φ는 가로 돌기예요!

주판봇

θ = 90°면 맨 꼭대기 북극이겠죠!

초파리 연구원

θ를 90°로 놓고 점이 어디 있는지 봐. 꼭대기야?

구면 좌표 실험 — 거리 r, 위아래 각 θ, 가로 각 φ

풀이 — 한 걸음씩

  1. r을 바꾸면 공 전체가 커지거나 작아지고 점은 같은 방향에 있어요.
  2. θ를 0°에서 180°로 바꾸면 점이 북극에서 남극까지 내려와요. 90°가 적도예요.
  3. φ를 바꾸면 점이 같은 위도선을 따라 가로로 돌아요.
  4. θ = 0°(북극)에서는 φ를 아무리 바꿔도 점이 그대로예요.
이 단계의 한계 — 북극·남극(θ = 0°, 180°)에서는 φ가 정해지지 않아요. 16장 공식의 1/(r·sin θ)가 극에서 곤란해지는 이유예요.
박사의 해석 — 구면 주소는 「크기 r」과 「방향 (θ, φ)」을 나눠 적는 주소예요. 방향만 비교하고 싶을 때 특히 편해요.
θ와 φ가 헷갈리면 정상이에요. 위아래 = θ, 가로 = φ 두 단어만 붙잡으세요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ③의 오른쪽 기둥 Spherical (r, θ, φ): 공 그림에서 θ는 +z축(북극)에서 잰 각, φ는 바닥에서 돈 각이에요. 이 약속은 물리학 교과서 방식이고, 수학 교과서에는 θ와 φ의 글자를 바꿔 쓰는 책도 있어요. 이 페이지는 원자료의 약속을 따릅니다.

2

2단계 · 큐브 주소로 바꾸기 — 삼각비 두 번

방법: 구면 → 큐브 변환일상: 손전등 그림자
박사

상황 질문 — 비스듬히 든 막대에 위에서 손전등을 비추면 바닥에 그림자가 생겨요. 그림자 길이는 무엇으로 정해질까요?

왜 이 방법을 쓰나

  1. 문제 상황: 구면 주소를 큐브 주소로 바꿔 거리·기울기 계산에 쓰고 싶어요.
  2. 앞 방법의 한계: 각도가 두 개라 한 번의 삼각비로는 안 돼요.
  3. 해법: ① 높이 z = r·cos θ와 바닥 그림자 길이 r·sin θ로 나누고, ② 그림자를 다시 φ로 x, y에 나눠요.
쉽게 말하면 — 먼저 위아래로 쪼개고, 그다음 가로로 쪼갠다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

x = r·sin θ·cos φ — 곱하기가 세 개나 돼요. 순서대로 하면 돼요?

학교 수학으로 보면: 중학교 3학년 삼각비를 두 번 쓰는 거예요. 04장 원기둥 변환에서 s 자리에 r·sin θ를 넣으면 돼요.

식 조각읽는 법뜻
z = r·cos θ제트는 알 코사인 세타높이 (θ가 작을수록 높음)
s = r·sin θ바닥 그림자 길이= 원기둥 주소의 s
x = s·cos φ, y = s·sin φ04장과 같음그림자를 가로·세로로 나누기
숫자로 한 번 해 보기

(r, θ, φ) = (2, 60°, 0°)

z = 2 × cos 60° = 2 × 0.5 = 1

s = 2 × sin 60° ≈ 2 × 0.866 = 1.73

φ = 0°라 x = 1.73, y = 0 → (1.73, 0, 1). 검산: √(3 + 0 + 1) = 2 = r ✓

조수 하루 (수강생)

구면 → 원기둥 → 큐브 순서로 두 번 바꾸는 거네요. 04장을 해 둔 게 이렇게 쓰이는구나.

일상으로 치면

비스듬히 든 막대의 그림자 길이는 막대 길이 × sin(기운 각)이고, 그림자가 어느 쪽으로 눕는지는 손전등을 돌린 각이 정해요.

수학에서는

구면 좌표 → 큐브: z = r·cos θ, x = r·sin θ·cos φ, y = r·sin θ·sin φ. 가운데 값 r·sin θ가 원기둥의 s예요.

조수 하루

(질문) θ = 90°면 cos 90° = 0이니 높이가 0, 적도 맞죠?

인턴 모아

맞아요! 그래서 적도 위의 점은 바닥 높이에 있어요.

초파리 연구원

r·sin θ가 원기둥 s랑 같다는 걸 그림의 점선으로 확인해 봐.

구면 주소 → 큐브 주소 계산

풀이 — 한 걸음씩

  1. 빨간 선(r)을 바닥에 내린 그림자가 회색 점선이에요. 길이 r·sin θ.
  2. 높이(z)는 r·cos θ예요. θ가 90°를 넘으면 z가 음수(아래쪽)예요.
  3. 그림자를 φ 방향으로 나누면 x, y가 나와요(04장과 같음).
  4. 세 값을 01장 거리 공식에 넣으면 언제나 r이 돌아와요.
이 단계의 한계 — 각도를 계산기에 넣을 때 「도(°)」인지 「라디안」인지 확인해야 해요. 같은 60이라도 결과가 완전히 달라져요.
박사의 해석 — 구면 주소는 원기둥 주소를 한 번 더 접은 것이에요. 16장 공식표에서 구면 공식에 r과 r·sin θ가 붙는 이유가 이 두 번의 접기 때문이에요.

3단계 · 공 모양엔 구면 주소 — 방향과 크기 나누기

방법: 좌표계 고르기일상: 풍선 크기와 가리키는 방향
박사

상황 질문 — 풍선을 불면 크기는 커지지만, 풍선 위에 찍힌 점이 「어느 쪽」에 있는지는 그대로예요. 이걸 주소로 어떻게 나타낼까요?

왜 이 방법을 쓰나

  1. 문제 상황: 공 모양과 「방향」을 다루는 계산을 짧게 하고 싶어요.
  2. 앞 방법의 한계: 큐브 주소에서는 크기와 방향이 x, y, z 세 숫자에 섞여 있어요.
  3. 해법: 구면 주소는 크기 r과 방향 (θ, φ)를 따로 적어요. 공 껍질은 r = 상수 한 마디예요.
쉽게 말하면 — 크기는 r에, 방향은 θ와 φ에.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

방향만 비교하면 뭐가 좋아요?

학교 수학으로 보면: 02장 단위 벡터와 같은 생각이에요. 길이를 1로 맞추면 방향만 남죠.

식 조각읽는 법뜻
r = 2알은 이반지름 2인 공 껍질
θ = 45°세타는 사십오 도북극에서 45° 내려온 원뿔
(θ, φ)방향크기와 상관없이 「어느 쪽」만 담은 정보
숫자로 한 번 해 보기

공 껍질: 큐브 x² + y² + z² = 4, 원기둥 s² + z² = 4, 구면 r = 2

원뿔 z = s(위쪽) ↔ 구면 θ = 45°

같은 방향 두 점 (1, 30°, 40°)와 (5, 30°, 40°): 방향 같음, 크기만 5배

단어 벡터 두 개의 「방향」이 비슷하면 뜻이 비슷하다고 보는 AI 계산(코사인 유사도)도 같은 생각

초파리 연구원

바닥판(z = 1)도 구면 주소로 써 봐. 짧아?

같은 모양, 세 가지 주소 식

풀이 — 한 걸음씩

  1. 공 껍질은 구면 주소로 r = 2, 가장 짧아요.
  2. 원뿔은 구면 주소로 θ = 45°, 각도 하나예요.
  3. 바닥판은 구면 주소로 r·cos θ = 1 — 큐브 주소 z = 1보다 길어요.
  4. 정답은 「모양에 따라」. 지구본조 발표의 결론도 같았어요.
이 단계의 한계 — 구면 주소가 늘 좋은 건 아니에요. 네모난 방, 평평한 바닥에는 큐브 주소가 더 짧고, 계산 공식(16장)도 큐브가 가장 간단해요.
박사의 해석 — 세 좌표계는 같은 공간의 세 가지 이름표예요. 문제의 모양을 먼저 보고 이름표를 고르는 것, 그게 이 기둥 1의 결론이에요.

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

X3이 AI에게 「구면 주소 (r, θ, φ) = (2, 60°, 0°)를 큐브 주소로 바꿔 줘」라고 했더니 이렇게 답했어요.

AI 답변: x = r·cos θ = 1, y = 0, z = r·sin θ ≈ 1.73이므로 (1, 0, 1.73)입니다.
박사

구면 좌표는 책마다 각도 약속이 달라요. AI 답을 받으면 「θ를 어디서 쟀나」부터 물어보세요. 북극 점(θ = 0°) 하나만 넣어 봐도 약속이 드러나요.
