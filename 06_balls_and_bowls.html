공·럭비공·그릇 — 식으로 읽는 곡면 1

핵심 질문 — x² + y² + z² = 4 같은 식 한 줄만 보고, 그 모양을 머릿속에 그릴 수 있을까?

곡면 도감(원자료 ④)에는 11가지 모양이 식과 함께 있어요. 이번 장에서는 그중 「닫힌 공」과 「그릇」 가족 — 구, 타원면, 타원포물면 — 을 읽어요. 그릇 모양은 10장에서 AI가 학습할 때 내려가는 「손실 그릇」으로 다시 만나요.

r = 3x² + y² + z² = 9인 공의 반지름
6x²/4 + y²/9 + z² = 1의 가장 긴 지름
타원그릇을 수평으로 자른 단면
0그릇 z = x² + y²의 가장 낮은 높이

숫자 요약은 이 장의 예시 계산에서 나온 값입니다(실제 데이터가 아닌 설명용 값).

박사

오늘은 조별 토론이에요. 큐브조는 「식만 보고 맞힐 수 있다」, 지구본조는 「그림이 있어야 한다」 쪽이에요.

인턴 시아

저희 큐브조는 식의 숫자 하나하나가 모양의 무엇을 정하는지 표로 정리해 왔어요.

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 공(구), 럭비공(타원면), 그릇(타원포물면)의 식을 읽고, 식의 숫자가 모양의 크기·늘어남을 어떻게 정하는지 배웁니다.
  2. 왜 중요한가: 식으로 모양을 읽을 줄 알면, 10장에서 AI의 손실 함수가 왜 「그릇 모양」이어야 학습이 잘 되는지 이해할 수 있어요.
  3. 생활·현장에서는: 안테나 접시(포물면), 캡슐 모양 알약(타원면), 3D 프린터와 게임 그래픽의 모양 데이터가 이런 식으로 저장돼요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

영어 기호·약어 풀이 (펼치기)
  • a, b, c — 각 축 방향으로 늘어난 정도 (반지름 역할)
  • x²/a² — x를 a로 나눈 뒤 제곱한 것
  • 단면 — 곡면을 평면으로 자른 자리에 생기는 곡선
  • = 1 — 「중심에서 늘어난 거리 1만큼」이라는 뜻

30초 복습 — 원의 방정식
중심이 원점이고 반지름이 r인 원: x² + y² = r². 원 위의 점은 모두 원점에서 거리 r이에요 (01장 거리 공식).

곡면 이름은 길지만 외울 필요 없어요. 「공, 럭비공, 그릇」이라는 별명이면 충분합니다.

1

1단계 · 공 — 식은 「거리가 r」이라는 조건

방법: 구의 방정식일상: 풍선 표면
박사

상황 질문 — 풍선 표면의 점들은 모두 어떤 공통점을 가지고 있을까요? 풍선 꼭지(중심)에서 재 보면?

왜 이 방법을 쓰나

  1. 문제 상황: 「공 모양」을 숫자 조건으로 적고 싶어요.
  2. 앞 방법의 한계: 「둥글다」는 말만으로는 컴퓨터가 어느 점이 공 위에 있는지 판단할 수 없어요.
  3. 해법: 중심에서 거리가 r인 점들을 모은 것이 공 껍질(구). 거리 공식을 제곱하면 x² + y² + z² = r².
쉽게 말하면 — 공 = 중심에서 거리가 똑같은 점들의 모임.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

오른쪽에 r²이라고 쓰는데, 왜 r이 아니라 제곱이에요?

학교 수학으로 보면: 중학교 원의 방정식 x² + y² = r²에 z²을 더한 거예요. 01장 거리 공식의 루트를 없애려고 양쪽을 제곱한 것이에요.

식 조각읽는 법뜻
x² + y² + z² = r²구의 방정식원점에서 거리 r인 점들
r반지름오른쪽 수의 제곱근
= 9오른쪽 값반지름의 제곱. 반지름은 √9 = 3
숫자로 한 번 해 보기

x² + y² + z² = 9 → 반지름 √9 = 3

점 (1, 2, 2): 1 + 4 + 4 = 9 → 공 위 ✓

점 (2, 2, 2): 4 + 4 + 4 = 12 > 9 → 공 밖

구면 주소로는 r = 3 한 마디 (05장)

조수 하루 (수강생)

식에 점을 넣어 보면 공 위인지, 안인지, 밖인지 바로 알 수 있네요. 숫자 판정기 같아요.

일상으로 치면

풍선 표면의 점은 꼭지(중심)에서 재면 모두 같은 거리에 있어요.

수학에서는

구는 중심에서 거리가 r인 점들의 모임이에요. 식 x² + y² + z² = r²은 01장 거리 공식을 제곱한 것이에요.

박사

반지름을 바꾸며 식의 오른쪽 수가 어떻게 바뀌는지 보세요. 단면도 켜 보세요.

주판봇

오른쪽이 9면 반지름도 9죠!

초파리 연구원

반지름을 1.5로 두면 오른쪽이 얼마로 나와? 그걸 보면 알 거야.

곡면 도감 ① — 공

풀이 — 한 걸음씩

  1. 반지름 r을 바꾸면 식의 오른쪽이 r²으로 바뀌어요(1.5 → 2.25).
  2. 단면을 켜면 공을 높이 z에서 자른 자리가 빨간 원으로 나와요.
  3. 자르는 높이를 반지름보다 크게 올리면 「아무것도 없음」이 나와요.
  4. 가운데(z = 0)에서 자를 때 원이 가장 커요.
이 단계의 한계 — 식 = r²는 「껍질」만 뜻해요. 속이 꽉 찬 공은 ≤ r²로 써요. 그림은 껍질이에요.
박사의 해석 — 곡면의 식은 「이 점이 모양 위에 있나?」를 판정하는 규칙이에요. 숫자를 넣어 양쪽이 같으면 위, 아니면 안이나 밖.
원자료 인포그래픽 보기 (영어 그림)

원자료 ④의 SPHERE: x² + y² + z² = r².

2단계 · 럭비공 — 축마다 다르게 늘인 공

방법: 타원면일상: 눌린 찰흙 공
박사

상황 질문 — 찰흙 공을 양손으로 눌러 길쭉하게 만들면, 식은 어떻게 바뀔까요?

왜 이 방법을 쓰나

  1. 문제 상황: 방향마다 길이가 다른 둥근 모양을 적고 싶어요.
  2. 앞 방법의 한계: 공의 식은 세 방향의 크기가 모두 r로 같아서, 길쭉한 모양을 담지 못해요.
  3. 해법: 축마다 늘이는 수 a, b, c로 나눠요: x²/a² + y²/b² + z²/c² = 1. a, b, c가 각 방향의 반지름이에요.
쉽게 말하면 — 공을 x로 a배, y로 b배, z로 c배 늘인 것.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

x²/4에서 4는 지름이에요, 반지름이에요?

학교 수학으로 보면: 분수와 제곱근 계산이에요. 분모는 「반지름의 제곱」이라 반지름은 √4 = 2예요.

식 조각읽는 법뜻
x²/a² + y²/b² + z²/c² = 1타원면축마다 반지름이 a, b, c
a = b = c세 값이 같을 때그냥 공(구)
x = ±a축과 만나는 곳y = z = 0을 넣으면 x² = a²
숫자로 한 번 해 보기

x²/4 + y²/9 + z²/1 = 1

x축과 만나는 곳: x² = 4 → x = ±2 (반지름 2)

y축: y = ±3, z축: z = ±1

가장 긴 지름 = 3 × 2 = 6 (분모 9를 그대로 쓰면 18로 틀려요)

조수 하루 (수강생)

분모는 반지름의 「제곱」이라 루트를 먼저 씌우면 되네요. 조교 대결 예고인 것 같은데요?

일상으로 치면

찰흙 공을 위에서 누르면 납작해지고(c가 작아짐), 옆으로 당기면 길쭉해져요(a가 커짐).

수학에서는

타원면 x²/a² + y²/b² + z²/c² = 1. 세 반지름 a, b, c가 모두 같으면 구예요. 단면은 모두 타원이에요.

박사

a, b, c를 따로 움직여 럭비공과 공깃돌을 만들어 보세요.

인턴 모아

식에 1이 있으면 반지름이 1인 거 아니에요?

초파리 연구원

a = b = c로 맞추고 「공」 식과 비교해 봐.

곡면 도감 ② — 공과 럭비공

풀이 — 한 걸음씩

  1. a를 키우면 x 방향으로만 길어지고, 식의 x² 분모가 a²으로 바뀌어요.
  2. 세 값을 같게 맞추면 공이 돼요. 양변에 a²을 곱하면 공의 식과 같아요.
  3. 단면은 원이 아니라 타원이에요. 높이를 올릴수록 타원이 작아져요.
  4. 오른쪽의 1은 반지름이 아니라 「늘이기 전 공의 반지름 1」이라는 약속이에요.
이 단계의 한계 — 그림의 타원면은 축과 나란히 늘인 것뿐이에요. 비스듬히 기운 럭비공은 xy 같은 섞인 항이 생기는데, 14장 헤시안에서 그 항(b)을 다뤄요.
박사의 해석 — 타원면 식의 분모는 「방향마다의 크기」예요. 14장에서 그릇의 「방향마다 휨」을 행렬로 읽을 때 같은 생각을 써요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ④의 ELLIPSOID: x²/a² + y²/b² + z²/c² = 1.

3단계 · 그릇 — 위로 열린 타원포물면

방법: 타원포물면과 단면일상: 국그릇과 등고선
박사

상황 질문 — 국그릇에 물을 조금씩 부으면, 물 표면의 모양은 어떻게 커질까요?

왜 이 방법을 쓰나

  1. 문제 상황: 바닥이 하나 있고 위로 끝없이 열린 모양을 적고 싶어요.
  2. 앞 방법의 한계: 공과 럭비공은 닫혀 있어서 「가장 낮은 곳 하나」를 가진 열린 모양을 담지 못해요.
  3. 해법: z = x²/a² + y²/b²: 높이가 x², y²에 따라 커져요. 바닥은 원점 하나, 수평 단면은 타원이에요.
쉽게 말하면 — 어디서 출발하든 아래로 내려가면 한 바닥에 모이는 모양.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

공 식은 = 1인데 그릇 식은 z = 로 시작해요. 왜 모양이 달라져요?

학교 수학으로 보면: 중학교 3학년 이차함수 y = x²의 포물선을 한 바퀴 돌린 모양이에요.

식 조각읽는 법뜻
z = x²/a² + y²/b²타원포물면높이 = 두 방향 제곱의 합
z = h에서 단면높이 h로 자르기x²/a² + y²/b² = h → 타원
최저점 (0, 0, 0)바닥x² ≥ 0, y² ≥ 0이라 z는 0보다 작아질 수 없음
숫자로 한 번 해 보기

z = x² + y² (a = b = 1)

(1, 1) → z = 2, (2, 0) → z = 4, (0, 0) → z = 0

높이 4로 자르면 x² + y² = 4 → 반지름 2인 원

높이 −1로 자르면 x² + y² = −1 → 아무것도 없음

조수 하루 (수강생)

제곱은 음수가 안 되니까 바닥이 0에서 딱 막히는 거네요. 그래서 그릇이 되는구나.

일상으로 치면

국그릇에 물을 부으면 물 표면은 점점 큰 동그라미(타원)가 되고, 맨 처음 한 방울은 바닥 한 점에 고여요.

수학에서는

타원포물면 z = x²/a² + y²/b²은 바닥이 하나인 그릇이에요. 수평 단면(등고선)은 타원. AI의 손실 함수가 이런 그릇이면 경사 하강(10장)으로 바닥을 쉽게 찾아요.

주판봇

초파리 연구원

a = 2, b = 1로 다르게 해 봐. 그래도 동그라미야?

곡면 도감 ③ — 그릇과 단면(등고선)

풀이 — 한 걸음씩

  1. 단면을 높일수록 타원이 커져요. 위에서 보면 동심 타원 — 이것이 등고선 지도(09장)예요.
  2. a ≠ b면 단면은 원이 아니라 타원이에요. 한쪽으로 더 완만한 그릇이에요.
  3. 높이를 0보다 낮추면 단면이 없어요. 그릇 바닥 아래에는 아무것도 없죠.
  4. 이 그릇의 가장 낮은 점은 (0, 0, 0) 하나뿐이에요.
이 단계의 한계 — 실제 AI의 손실 「그릇」은 차원이 수백만이고, 완벽한 그릇이 아니라 울퉁불퉁해요. 여기서는 단순하게 가장 깔끔한 그릇만 봤어요.
박사의 해석 — 그릇 모양이면 「어디서 출발하든 내리막만 따라가면 바닥」이에요. 이 성질 때문에 AI는 손실 함수를 그릇에 가깝게 만들려고 노력해요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ④의 ELLIPTIC PARABOLOID: z = x²/a² + y²/b².

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

모아가 AI에게 「x² + y² + z² = 9인 공의 반지름과 겉넓이」를 물었더니 이렇게 답했어요.

AI 답변: 반지름은 9입니다. 겉넓이는 4πr² = 4π × 81 = 324π입니다.

AI의 계산이 길게 이어질수록 「첫 숫자」를 먼저 확인하세요. 점 하나(예: (3, 0, 0))를 식에 넣어 보면 반지름이 맞는지 바로 드러나요.
