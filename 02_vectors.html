기둥 1 · 자리를 정하는 법 · 02장 · 오늘의 수업: 조별 과제 · 기본 과정 · 난이도 입문 ●○○ · 본편 약 25분

벡터 — 크기와 방향을 가진 화살표

핵심 질문 — 「얼마나」와 「어느 쪽으로」를 한꺼번에 적으려면 무엇이 필요할까?

바람은 「초속 5m」만으로는 부족하고 「북동쪽으로」가 함께 있어야 해요. 크기와 방향을 함께 담은 화살표를 벡터라고 불러요. 1장의 숫자 세 개가 이번에는 점이 아니라 화살표가 됩니다.

2가지벡터가 담는 정보: 크기와 방향
5화살표 (3, 4)의 길이
7 ≠ 5길이 3과 4를 더해도 7이 아닐 수 있음
1단위 벡터의 길이

숫자 요약은 이 장의 예시 계산에서 나온 값입니다(실제 데이터가 아닌 설명용 값).

박사

오늘은 조별 과제예요. 과제는 하나, 「화살표를 숫자로, 숫자를 화살표로」.

인턴 시아

1조는 모눈종이에 그려서, 2조는 숫자 계산으로 풀어 보기로 했어요.

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 크기와 방향을 함께 가진 양(벡터)을 화살표와 숫자 묶음 두 가지로 나타내고, 더하기·늘이기·길이 1로 줄이기를 배웁니다.
  2. 왜 중요한가: 기울기(그래디언트), 흐름(벡터장), AI의 입력 데이터가 모두 벡터예요. 벡터 계산은 이 교실의 기본 문법입니다.
  3. 생활·현장에서는: 바람과 물살, 게임 캐릭터의 이동, 내비게이션의 「여기서 북동쪽 300m」가 모두 벡터예요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

영어 기호·약어 풀이 (펼치기)
  • a = (a₁, a₂) — 벡터 a의 성분. a₁은 가로, a₂는 세로
  • |a| — 벡터 a의 길이(크기)
  • â — 에이 햇. 길이 1로 줄인 a (방향만)
  • ka — 벡터 a를 k배로 늘인 것

등장인물 — 선생님 1명, 조교 2명, 수강생 6명

선생님박사목소리는 크지만 판단은 계산대로. 막히는 곳에서 꼭 멈춰 줍니다.
조교 (의심 담당)초파리 연구원작지만 날카롭다. "정말 그래?" 하고 반례와 검산을 들고 옵니다.
조교 (확신 담당)주판봇공식과 빠른 계산을 좋아한다. 가끔 너무 빨리 확신합니다.
수강생 · 1조인턴 시아조용하고 꼼꼼한 정리 담당. 표와 그림으로 정리하는 걸 좋아해요.
수강생 · 2조인턴 모아상냥하고 잘 웃는다. 발표와 응원 목소리가 제일 커요.
수강생 · 1조조수 하루수식이 나오면 손을 번쩍 드는 질문 담당. 처음 오신 분의 눈높이.
수강생 · 1조미공개 X1정체는 비밀. 짧고 엉뚱한 질문을 던진다.
수강생 · 2조미공개 X2정체는 비밀. 조용히 그림을 그려 온다.
수강생 · 2조미공개 X3정체는 비밀. 숫자 세기와 손계산을 좋아한다.

조별 과제

1조 「큐브조」와 2조 「지구본조」가 같은 과제를 받아 서로 다른 방법으로 풀고 결과를 비교합니다.

1조 「큐브조」 시아 · 하루 · X1
2조 「지구본조」 모아 · X2 · X3
  1. 박사의 과제 소개: 「화살표 세 장 — 그리기, 더하기, 줄이기」
  2. 1조 큐브조는 모눈종이 그림으로, 2조 지구본조는 성분 계산으로 같은 문제 풀기
  3. 두 조의 답을 맞춰 보며 「그림 = 숫자」 확인
  4. 조교 대결: 길이 3과 4인 화살표를 더하면 길이 7일까?
미공개 X2

…저는 화살표를 색연필로 그려 왔어요.

인턴 모아

2조는 계산기 들고 왔어요! 그림이랑 숫자랑 누가 빠른지 해 봐요!

왜 이 주제를 배우나

1방향이 있는 양을 다루려고

속도, 힘, 바람, 기울기는 크기만으로는 설명이 안 돼요. 방향까지 담는 그릇이 필요해요.

2여러 움직임을 합치려고

「동쪽으로 3, 북쪽으로 4」를 한 번에 가면 어디인지 — 화살표 더하기가 답해요.

3AI의 기본 단위라서

AI 안에서 데이터 한 줄, 단어 하나, 기울기 하나가 모두 벡터(숫자 묶음)로 움직여요.

큰 그림 — 지금 어디쯤 있나

앞에서 배운 것01장 좌표 (x, y, z)와 거리 공식
→
이번 장벡터 — 화살표 = 성분 묶음 → 더하기 → 단위 벡터
→
다음에 쓰는 곳03장 행렬(벡터를 바꾸는 기계), 09장 그래디언트(기울기 벡터), 12장 흐름(벡터장)
30초 복습 — 피타고라스 정리
직각삼각형에서 빗변² = 밑변² + 높이². 밑변 3, 높이 4면 빗변은 √25 = 5 (01장에서 거리 구할 때 썼어요).

점과 화살표는 같은 숫자 묶음으로 적지만 뜻이 달라요. 점은 「자리」, 화살표는 「움직임」이에요.

1

1단계 · 화살표 = 숫자 묶음

방법: 벡터의 성분일상: 보물 지도 지시문
박사

상황 질문 — 보물 지도에 「동쪽으로 3걸음, 북쪽으로 2걸음」이라고 적혀 있어요. 이걸 화살표 하나로 그릴 수 있을까요?

왜 이 방법을 쓰나

  1. 문제 상황: 움직임 하나를 크기와 방향까지 담아 적고 싶어요.
  2. 앞 방법의 한계: 「5걸음」만 적으면 방향을 모르고, 「북동쪽」만 적으면 거리를 몰라요.
  3. 해법: 가로로 몇, 세로로 몇(성분)을 적으면 화살표 하나가 정해지고, 길이와 방향은 거기서 계산돼요.
쉽게 말하면 — 「오른쪽으로 몇, 위로 몇」이 곧 화살표.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

a = (3, 2)는 1장의 점 (3, 2)랑 똑같이 생겼는데 뭐가 달라요?

학교 수학으로 보면: 중학교 좌표평면의 점 (3, 2)로 가는 「이동」이에요. 길이는 피타고라스 정리로 구해요.

식 조각읽는 법뜻
a = (a₁, a₂)에이는 에이 일, 에이 이가로 성분 a₁, 세로 성분 a₂
|a| = √(a₁² + a₂²)에이의 크기화살표의 길이 (01장 거리 공식과 같음)
방향각도오른쪽 가로선에서 돌아간 각도
숫자로 한 번 해 보기

a = (3, 4) → 오른쪽으로 3, 위로 4

길이 |a| = √(3² + 4²) = √25 = 5

어디서 출발하든 「오른쪽 3, 위로 4」면 같은 화살표

3차원도 같아요: (1, 2, 2)의 길이 = √(1 + 4 + 4) = 3

조수 하루 (수강생)

점은 「어디」고 화살표는 「어디서 어디로」구나. 출발점을 옮겨도 같은 화살표라는 게 핵심이네요.

일상으로 치면

보물 지도의 「동쪽 3걸음, 북쪽 2걸음」은 어느 나무에서 시작하든 같은 움직임이에요.

수학에서는

벡터는 크기와 방향을 가진 양이고, 성분 (a₁, a₂, a₃)로 적어요. 길이는 |a| = √(a₁² + a₂² + a₃²).

박사

가로와 세로 성분을 움직여 화살표 길이가 어떻게 바뀌는지 보세요.

주판봇

길이는 3 + 4 = 7이죠!

초파리 연구원

(3, 4)로 맞춰 놓고 길이 숫자를 직접 읽어 봐.

화살표 실험 — 성분을 바꾸며 길이와 방향 보기

풀이 — 한 걸음씩

  1. 주황 점선은 가로 성분, 초록 점선은 세로 성분이에요. 둘은 직각이라 피타고라스가 그대로 쓰여요.
  2. (3, 4)로 맞추면 길이가 정확히 5예요.
  3. (−3, 0)처럼 음수 성분은 왼쪽(또는 아래쪽)을 뜻해요.
  4. (0, 0)은 길이 0인 화살표 — 방향이 없어요.
이 단계의 한계 — 그림은 평면(성분 2개)이지만, 3차원 화살표도 성분 3개로 똑같이 다뤄요. AI에서는 성분이 수백 개인 벡터도 흔해요.
박사의 해석 — 벡터를 성분으로 적으면 「그림을 그리지 않고도」 길이와 방향을 계산할 수 있어요. 이것이 컴퓨터가 벡터를 다루는 방식이에요.
음수 성분에서 헷갈렸다면 정상이에요. 「−는 반대쪽」 하나만 기억하세요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ③ 아래쪽 Base vectors: 큐브 좌표의 단위 벡터 x̂, ŷ, ẑ. 모든 벡터는 이 세 화살표를 몇 배씩 더한 것이에요.

2

2단계 · 화살표 더하기와 늘이기

방법: 벡터 덧셈·실수배일상: 강을 건너는 배
박사

상황 질문 — 배가 동쪽으로 3m/s로 가는데 강물이 북쪽으로 4m/s로 흐르면, 배는 실제로 어느 쪽으로 얼마나 빨리 갈까요?

왜 이 방법을 쓰나

  1. 문제 상황: 두 움직임이 함께 일어날 때 결과 움직임을 알고 싶어요.
  2. 앞 방법의 한계: 빠르기만 더하면(3 + 4 = 7) 방향이 다를 때 틀려요.
  3. 해법: 화살표를 꼬리에 머리를 이어 붙이고(그림), 성분끼리 더해요(숫자). 둘은 같은 결과예요.
쉽게 말하면 — 성분끼리 더하고, 길이는 마지막에 다시 잰다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

화살표를 더하는데 왜 길이는 그냥 더하면 안 돼요?

학교 수학으로 보면: 중학교 「삼각형의 두 변의 길이의 합은 나머지 한 변보다 크다」와 같은 이야기예요.

식 조각읽는 법뜻
a + b = (a₁ + b₁, a₂ + b₂)에이 더하기 비성분끼리 더하기
ka = (ka₁, ka₂)케이 에이k배 늘이기. k가 음수면 방향이 뒤집힘
|a + b| ≤ |a| + |b|삼각 부등식같은 방향일 때만 등호
숫자로 한 번 해 보기

배 a = (3, 0), 강물 b = (0, 4)

a + b = (3 + 0, 0 + 4) = (3, 4)

실제 빠르기 |a + b| = √(9 + 16) = 5 m/s (7이 아님)

2a = (6, 0) — 같은 방향, 길이 2배

조수 하루 (수강생)

성분끼리 더하는 건 그냥 덧셈이라 할 만하네요. 길이만 마지막에 루트로 다시 재면 되고요.

일상으로 치면

강을 건너는 배는 앞으로 나아가는 힘과 옆으로 미는 물살이 합쳐져 비스듬히 가요.

수학에서는

벡터 덧셈은 성분끼리 더하기, 실수배는 성분마다 곱하기예요. 그림으로는 꼬리-머리 잇기와 늘이기.

박사

파란 a 끝에 보라 b를 이어 붙였어요. 빨간 합과 길이를 비교해 보세요.

인턴 모아

길이가 3이랑 4면 합은 무조건 7 아니에요?

초파리 연구원

b를 a와 같은 방향으로 돌려 봐. 그때만 7이 되는지.

화살표 더하기 — a와 b를 이어 붙이기

풀이 — 한 걸음씩

  1. 파란 a의 머리에 보라 b의 꼬리를 붙이면, 처음 꼬리에서 마지막 머리까지가 빨간 a + b예요.
  2. 성분으로 보면 가로끼리, 세로끼리 더한 값과 같아요.
  3. |a| + |b|는 |a + b|보다 크거나 같아요. 같은 방향일 때만 같아져요.
  4. b = −a로 두면 합은 (0, 0) — 서로 지워져요.
이 단계의 한계 — 「더하기」가 뜻이 있으려면 두 벡터가 같은 종류(둘 다 속도, 둘 다 힘)여야 해요. 속도와 위치를 더하는 건 뜻이 없어요.
박사의 해석 — 여러 힘·바람·기울기를 한꺼번에 받을 때 결과는 화살표의 합이에요. 경사 하강(10장)에서 매 걸음 위치에 「기울기 화살표 × 걸음 크기」를 더하는 것도 이 계산이에요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ② 맨 위의 ∇ = î ∂/∂x + ĵ ∂/∂y + k̂ ∂/∂z도 「단위 벡터를 몇 배씩 더한 것」이라는 같은 꼴이에요(î, ĵ, k̂는 x̂, ŷ, ẑ의 다른 이름).

3단계 · 단위 벡터 — 길이 1짜리 방향표

방법: 단위 벡터 x̂·ŷ·ẑ일상: 나침반 바늘
박사

상황 질문 — 나침반 바늘은 얼마나 센 바람이 부는지는 알려 주지 않아요. 바늘은 무엇만 알려 줄까요?

왜 이 방법을 쓰나

  1. 문제 상황: 방향만 따로 떼어 내고 싶어요.
  2. 앞 방법의 한계: 벡터에는 크기와 방향이 섞여 있어서, 「방향만」 비교하기 어려워요.
  3. 해법: 벡터를 자기 길이로 나눠 길이 1짜리로 만들어요(단위 벡터). 세 축 방향의 단위 벡터 x̂, ŷ, ẑ로는 모든 벡터를 조립해요.
쉽게 말하면 — 길이를 1로 맞추면 남는 건 방향뿐.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

x̂처럼 글자에 모자를 씌우는 건 무슨 뜻이에요?

학교 수학으로 보면: 분수 계산이에요. 각 성분을 길이로 나누면 돼요.

식 조각읽는 법뜻
â = a / |a|에이 햇은 에이 나누기 에이의 크기길이 1, 방향은 a와 같음
x̂ = (1, 0, 0)엑스 햇x축 방향 단위 벡터
a = 3x̂ + 4ŷ삼 엑스햇 더하기 사 와이햇(3, 4)를 단위 벡터로 조립한 모습
숫자로 한 번 해 보기

a = (3, 4), |a| = 5

â = (3/5, 4/5) = (0.6, 0.8)

검산: √(0.36 + 0.64) = √1 = 1 ✓

(3, 4) = 3 × (1, 0) + 4 × (0, 1) = 3x̂ + 4ŷ

조수 하루 (수강생)

모자 쓴 글자는 「길이 1짜리 방향표」구나. 원자료 공식표에 x̂, ŝ, r̂ 같은 게 잔뜩 나왔던 이유를 알겠어요.

일상으로 치면

나침반 바늘은 길이가 늘 같아요. 바람이 세든 약하든 바늘은 「북쪽」이라는 방향만 알려 줘요.

수학에서는

단위 벡터 â = a / |a|는 길이 1인 방향표예요. 큐브 좌표의 x̂, ŷ, ẑ, 원기둥의 ŝ, φ̂, 구면의 r̂, θ̂, φ̂가 모두 단위 벡터예요.

박사

k를 바꿔 늘여 보고, 빨간 단위 화살표가 어디에 닿는지 보세요.

주판봇

길이 1로 줄이면 정보가 사라지니 쓸모없지 않아요?

초파리 연구원

k를 음수로 해 봐. 길이 말고 뭐가 바뀌지?

늘이기와 단위 벡터 — 길이는 바뀌어도 방향표는 그대로

풀이 — 한 걸음씩

  1. 보라 화살표는 a를 k배 늘인 것이에요. k가 음수면 방향이 반대로 뒤집혀요.
  2. 빨간 화살표는 a를 길이 1로 줄인 단위 벡터. 끝이 반지름 1인 점선 원 위에 있어요.
  3. k를 바꿔도 단위 벡터는 그대로예요(k가 양수일 때). 방향만 담고 있으니까요.
  4. (0, 0)은 길이가 0이라 나눌 수 없어 단위 벡터가 없어요.
이 단계의 한계 — 큐브 좌표의 x̂, ŷ, ẑ는 어디서나 같은 방향이지만, 원기둥·구면의 단위 벡터(ŝ, r̂ 등)는 자리마다 방향이 달라져요. 그래서 16장 공식이 복잡해져요.
박사의 해석 — 「방향 × 크기」로 나누어 생각하는 습관이 09장 그래디언트에서 그대로 쓰여요: 방향은 가장 가파른 쪽, 크기는 그 가파름.

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

모아가 AI에게 「동쪽으로 6km/h로 걷는데 북쪽에서 바람이 남쪽으로 8km/h로 불면, 땅에 대한 내 움직임의 빠르기는?」이라고 물었어요(머리카락처럼 가벼운 물체라고 가정).

AI 답변: 두 빠르기를 더하면 6 + 8 = 14km/h입니다. 방향은 동쪽입니다.

「빠르기」, 「힘」처럼 방향이 있는 양을 AI가 그냥 더했다면 의심하세요. 성분으로 나눠 더했는지 확인하는 게 첫 질문이에요.
