좌표가 바뀌면 공식도 바뀐다 — 같은 연산자, 다른 좌표

핵심 질문 — 같은 그래디언트·발산인데, 원기둥·구면 좌표에서는 왜 1/s, 1/r² 같은 낯선 항이 붙을까?

원자료 ③ 「Vector Derivatives — Same operators, different coordinates」는 같은 ∇, ∇·, ∇×, ∇²를 세 좌표계로 적은 공식표예요. 큐브 기둥은 깔끔한데 원기둥·구면 기둥은 복잡해요. 그 비밀은 표 맨 아래의 척도 인자 — 「각도 한 걸음이 실제로 몇 m인가」 — 에 있어요.

1, s, 1원기둥 좌표의 척도 인자
1, r, r·sin θ구면 좌표의 척도 인자

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 원기둥·구면 좌표에서 「각도 한 걸음」의 실제 거리를 알려 주는 척도 인자를 배우고, 그 때문에 그래디언트·발산·라플라시안 공식에 1/s, 1/r² 등이 붙는다는 것을 두 길 계산으로 확인합니다.
  2. 왜 중요한가: 둥근 물체(관, 공, 행성, 안테나)를 다루는 물리·공학 계산은 거의 이 공식표로 해요. 「좌표를 바꾸면 늘이는 수가 붙는다」는 생각은 AI가 데이터 좌표를 바꿀 때(정규화 흐름의 det J)에도 쓰여요.
  3. 생활·현장에서는: 원통형 수도관 속 물 흐름, 지구 대기의 바람, 스피커 소리의 퍼짐, 전선 둘레의 자기장이 원기둥·구면 공식으로 계산돼요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

원기둥 (s, φ, z): 축에서 거리, 도는 각, 높이(04장). 구면 (r, θ, φ): 중심 거리, 북극에서 내려온 각, 가로 각(05장).

이 장은 시리즈에서 가장 공식이 많은 장이에요. 1단계(척도 인자)만 이해해도 공식표의 비밀은 풀려요. 3단계는 심화로 접어 두었어요.

1

1단계 · 같은 각도 걸음, 다른 실제 거리 — 척도 인자

방법: 척도 인자 (1, s, 1 / 1, r, r·sin θ)일상: 회전목마 안쪽 말과 바깥쪽 말
박사

상황 질문 — 회전목마가 한 바퀴 돌 때, 안쪽 말과 바깥쪽 말 중 누가 더 먼 거리를 갈까요? 둘 다 360°를 돌았는데요.

왜 이 방법을 쓰나

  1. 문제 상황: 좌표 숫자의 변화를 실제 거리로 바꾸고 싶어요.
  2. 앞 방법의 한계: 큐브 좌표는 「숫자 1 = 거리 1」이지만, 각도 φ는 1 늘어도 실제 거리가 자리마다 달라요.
  3. 해법: 「좌표 1만큼 = 실제 거리 몇」을 척도 인자라 불러요. 원기둥은 s 방향 1, φ 방향 s, z 방향 1. 구면은 1, r, r·sin θ.
쉽게 말하면 — 바깥일수록 같은 각도가 더 긴 길.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

척도 인자 s는 04장의 그 s예요? 왜 각도에 거리가 곱해져요?

학교 수학으로 보면: 중학교 「부채꼴의 호의 길이 = 반지름 × 중심각(라디안)」이에요. 각도 φ를 라디안으로 잴 때, 반지름 s인 원 위에서 φ만큼 가면 실제 길이는 s·φ.

식 조각읽는 법뜻
호의 길이 = s × Δφ원기둥 φ 방향척도 인자 h_φ = s
호의 길이 = r × Δθ구면 θ 방향 (위아래)척도 인자 h_θ = r
호의 길이 = r·sin θ × Δφ구면 φ 방향 (가로)위도선의 반지름이 r·sin θ
숫자로 한 번 해 보기

Δφ = 20° ≈ 0.349 라디안

s = 1: 실제 거리 0.349, s = 3: 1.047 (3배)

구면 r = 2, θ = 90°(적도): 2 × 1 × 0.349 = 0.698

구면 r = 2, θ = 10°(북극 근처): 2 × 0.174 × 0.349 ≈ 0.121 — 같은 각도인데 훨씬 짧음

조수 하루 (수강생)

극 근처에서는 경도 1°가 아주 짧은 거리라 r·sin θ가 0에 가까워지는구나. 지구본에서 경도선이 위에서 모이는 이유네요.

일상으로 치면

회전목마 바깥쪽 말은 안쪽 말보다 같은 360°를 돌아도 훨씬 먼 거리를 달려요. 반지름이 클수록 「한 바퀴」가 길어요.

수학에서는

척도 인자는 「좌표 숫자 1만큼이 실제 거리로 얼마인지」예요. 원자료 ③ 맨 아래: 큐브 1, 1, 1 / 원기둥 1, s, 1 / 구면 1, r, r·sin θ.

초파리 연구원

(발표) s나 r을 바꿔 보고, 빨간 호의 길이를 비교해 봐.

조수 하루

(질문) 그럼 「φ 방향 기울기」를 잴 때도 각도당 변화가 아니라 거리당 변화로 바꿔야겠네요?

주판봇

각도 20°는 어디서나 20°니까 거리도 같죠!

척도 인자 — 각도 한 걸음의 실제 길이

풀이 — 한 걸음씩

  1. 빨간 호가 φ로 20° 간 실제 길이예요. s(또는 r)가 클수록 길어요.
  2. 오른쪽 막대는 반지름별 실제 길이예요. 반지름에 정비례해요.
  3. 구면으로 바꾸고 θ를 10°나 170°로 두면, 같은 r이라도 호가 아주 짧아져요(극 근처).
  4. 「각도당 변화」를 「거리당 변화」로 바꾸려면 척도 인자로 나눠야 해요 — 다음 단계의 1/s.
이 단계의 한계 — 척도 인자는 서로 직각인 좌표계(직교 좌표계)에서만 이렇게 깔끔해요. 비스듬한 좌표계는 행렬(계량 텐서)이 필요해요.
박사의 해석 — 공식표의 복잡함은 대부분 「각도 걸음을 실제 거리로 바꾸는 수」 때문이에요. 11장 극좌표 야코비안의 det J = r도 같은 이야기예요(넓이 배율 = 척도 인자의 곱).
라디안이 낯설면 「180° = 3.14」 하나만 기억하세요. 20°는 그 9분의 1인 약 0.349예요.

2

2단계 · 원기둥 좌표의 그래디언트 — 왜 1/s인가

방법: ∇t = ∂t/∂s ŝ + (1/s)∂t/∂φ φ̂ + ∂t/∂z ẑ일상: 등대 불빛의 각도
박사

상황 질문 — 등대 불빛이 1초에 1라디안씩 돌아요. 등대에서 1km 떨어진 배와 10km 떨어진 배가 느끼는 「불빛이 지나가는 빠르기」는 같을까요?

왜 이 방법을 쓰나

  1. 문제 상황: 원기둥 주소로 쓴 함수의 그래디언트를 바로 구하고 싶어요.
  2. 앞 방법의 한계: ∂f/∂φ는 「각도 1당 변화」라서, 그대로 화살표 성분으로 쓰면 거리당 변화가 아니라 틀려요.
  3. 해법: 각도당 변화를 그 자리의 척도 인자 s로 나눠 거리당 변화로 바꿔요: φ 성분 = (1/s)·∂f/∂φ.
쉽게 말하면 — 각도당 변화 ÷ 실제 걸음 길이 = 거리당 변화.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

f = φ면 φ로 미분해서 1인데, 왜 그래디언트 길이가 1이 아니에요?

학교 수학으로 보면: 「변화량 ÷ 거리」라는 기울기의 뜻(08장)으로 돌아가면 돼요. 각도 1이 실제로 s m라면, 거리당 변화는 1 ÷ s.

식 조각읽는 법뜻
∂f/∂ss 방향 기울기척도 인자 1 → 그대로
(1/s)·∂f/∂φφ 방향 기울기척도 인자 s로 나눔
∂f/∂zz 방향 기울기척도 인자 1 → 그대로
숫자로 한 번 해 보기

f = φ (각도 자체), 점 s = 2

∂f/∂s = 0, ∂f/∂φ = 1 → φ 성분 = 1/2 = 0.5

큐브 좌표 검산: f = atan(y/x) → |∇f| = 1/√(x² + y²) = 1/2 = 0.5 ✓

1/s를 빼먹으면 1 — 두 배로 틀림

조수 하루 (수강생)

각도 1이 2m짜리 걸음이라서 0.5가 되는 거였네요. 공식이 「단위 바꾸기」였어요.

일상으로 치면

등대 불빛은 멀리 있는 배일수록 더 빠르게 휙 지나가요. 같은 「각도 빠르기」라도 거리가 멀면 실제 빠르기가 달라요.

수학에서는

원기둥 그래디언트 ∇t = ∂t/∂s ŝ + (1/s)·∂t/∂φ φ̂ + ∂t/∂z ẑ. 1/s는 각도당 변화를 거리당 변화로 바꾸는 척도 인자의 역수예요.

초파리 연구원

1/s를 빼먹은 화살표야. s를 바꾸면 얼마나 틀리는지 봐.

두 길 그래디언트 — 큐브 계산 vs 원기둥 공식

풀이 — 한 걸음씩

  1. 초록 굵은 화살표는 (x, y)로 바꿔 큐브 좌표에서 계산한 그래디언트예요.
  2. 빨간 화살표는 원기둥 공식(1/s 포함)으로 계산한 것 — 초록과 정확히 겹쳐요.
  3. 주황 점선은 1/s를 빼먹은 경우예요. s = 1에서만 우연히 맞고, s가 커질수록 크게 틀려요.
  4. f = s²은 φ에 따라 변하지 않아 1/s 항이 0 — 이때는 빼먹어도 티가 안 나요(함정!).
이 단계의 한계 — s = 0(축 위)에서는 1/s를 계산할 수 없어요. 축 위의 그래디언트는 큐브 좌표로 따로 구해야 해요.
박사의 해석 — 원자료 ③의 그래디언트 공식 셋은 모두 「편미분 ÷ 척도 인자」 모양이에요. 큐브는 1, 1, 1 / 원기둥은 1, s, 1 / 구면은 1, r, r·sin θ로 나눠요. 이 한 줄이 공식표 첫 줄 전체예요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ③의 Gradient 줄: 원기둥 ∇t = ∂t/∂s ŝ + (1/s)∂t/∂φ φ̂ + ∂t/∂z ẑ, 구면 ∇t = ∂t/∂r r̂ + (1/r)∂t/∂θ θ̂ + (1/(r sin θ))∂t/∂φ φ̂.

3단계 · 발산·회전·라플라시안 공식 — 두 길로 검산하기

방법: 곡선 좌표의 ∇·, ∇×, ∇²일상: 두 가지 지도로 같은 길 재기
박사

상황 질문 — 같은 산책로 길이를 동네 지도(네모 격자)와 등산 지도(둥근 등고선)로 각각 재면, 같은 답이 나와야 하지 않을까요?

왜 이 방법을 쓰나

  1. 문제 상황: 원자료 ③의 복잡한 발산·회전·라플라시안 공식이 정말 맞는지 확인하고 싶어요.
  2. 앞 방법의 한계: 공식이 길어서 외우거나 믿기 어렵고, 한 글자만 틀려도 결과가 달라져요.
  3. 해법: 같은 흐름·함수를 큐브 좌표와 둥근 좌표로 각각 계산해 같은 답이 나오는지 비교해요. 숫자 검산(아주 작은 걸음)까지 세 길로 확인해요.
쉽게 말하면 — 공식은 외우는 게 아니라, 두 길로 맞춰 보는 것.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

(1/r²)·∂(r²·v_r)/∂r에서 r²은 어디서 갑자기 나왔어요?

학교 수학으로 보면: 구의 겉넓이 4πr²이에요. 바깥으로 갈수록 상자의 벽 넓이가 r²에 비례해서 커지니, 「나가는 양」을 셀 때 r²을 곱했다가 부피로 나누면서 1/r²이 붙어요.

식 조각읽는 법뜻
(1/s)·∂(s·v_s)/∂s원기둥 발산의 첫 항바깥 벽 넓이가 s에 비례
(1/r²)·∂(r²·v_r)/∂r구면 발산의 첫 항바깥 벽 넓이가 r²에 비례
(1/r²)·∂(r²·∂f/∂r)/∂r구면 라플라시안의 첫 항그래디언트(∂f/∂r)의 구면 발산
숫자로 한 번 해 보기

v = (x, y, 0), 원기둥으로 v_s = s: (1/s)·∂(s²)/∂s = (1/s)·2s = 2, 큐브: 1 + 1 + 0 = 2 ✓

v = (x, y, z), 구면으로 v_r = r: (1/r²)·∂(r³)/∂r = 3, 큐브: 1 + 1 + 1 = 3 ✓

f = x² + y² + z² = r²: (1/r²)·∂(r²·2r)/∂r = (1/r²)·6r² = 6, 큐브: 2 + 2 + 2 = 6 ✓

f = 1/r: (1/r²)·∂(r²·(−1/r²))/∂r = (1/r²)·∂(−1)/∂r = 0 — 중력·전기 퍼텐셜은 라플라시안 0

조수 하루 (수강생)

공식이 길어도 결국 같은 답이 나오네요. 「바깥 벽 넓이」를 생각하니 r²이 왜 붙는지도 알겠어요.

일상으로 치면

같은 산책로를 동네 지도와 등산 지도로 재면 같은 길이가 나와야 해요. 다르면 어느 한쪽 계산이 틀린 거예요.

수학에서는

원자료 ③의 원기둥·구면 발산·회전·라플라시안 공식은 척도 인자로 벽 넓이와 걸음 길이를 보정한 것이에요. 큐브 좌표 계산과 언제나 같은 답을 줘요.

(질문) 1/r의 라플라시안이 0인 건 무슨 뜻이에요?

초파리 연구원

중심 말고는 어디서나 「이웃 평균과 같다」는 뜻이야. 그래서 중력이 그런 모양이 돼.

공식 검산기 — 큐브 길, 둥근 길, 숫자 검산

풀이 — 한 걸음씩

  1. 초록 줄은 큐브 좌표 계산, 빨간 줄은 원기둥·구면 공식 계산이에요.
  2. 주황 줄은 점 (0.7, 1.1, 0.4)에서 아주 작은 걸음으로 직접 계산한 숫자 검산이에요.
  3. 여섯 사례 모두 세 길이 같은 답이에요.
  4. 1/r의 라플라시안은 큐브 좌표로는 세 항이 복잡하게 지워지지만, 구면 공식으로는 한 줄에 0이 나와요 — 둥근 문제는 둥근 공식이 짧아요.
이 단계의 한계 — s = 0(원기둥 축)과 r = 0(구의 중심), 극(sin θ = 0)에서는 공식에 0으로 나누기가 생겨 그대로 쓸 수 없어요.
박사의 해석 — 공식표는 외울 대상이 아니라 「척도 인자로 보정한 같은 연산자」예요. 의심이 들면 큐브 좌표로 바꿔 검산하세요. 이것이 「Same operators, different coordinates」의 뜻이에요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ③의 Divergence·Curl·Laplacian 줄 (원기둥·구면 기둥). 이 페이지의 손계산과 숫자 검산으로 확인한 결과, 원자료 공식에서 틀린 곳은 찾지 못했어요.

더 알고 싶은 분께 — 정확한 정의 (몰라도 됩니다)

직교 곡선 좌표 (u₁, u₂, u₃), 척도 인자 h₁, h₂, h₃에서 ∇·v = (1/(h₁h₂h₃)) Σ ∂(vᵢ·h₁h₂h₃/hᵢ)/∂uᵢ, ∇²f = (1/(h₁h₂h₃)) Σ ∂((h₁h₂h₃/hᵢ²)·∂f/∂uᵢ)/∂uᵢ. 원기둥 (1, s, 1), 구면 (1, r, r sin θ)를 넣으면 원자료 ③의 식이 나온다(Griffiths, 2017, 부록 A).

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

X3이 AI에게 「원기둥 좌표에서 f = φ의 점 s = 4에서 그래디언트 크기」를 물었더니 이렇게 답했어요.

AI 답변: ∂f/∂s = 0, ∂f/∂φ = 1, ∂f/∂z = 0이므로 ∇f = (0, 1, 0)이고 크기는 1입니다.
박사

둥근 좌표에서 AI가 「편미분을 그대로 늘어놓았다면」 척도 인자를 빠뜨린 거예요. 큐브 좌표로 한 번 바꿔 검산하는 습관을 들이세요.
