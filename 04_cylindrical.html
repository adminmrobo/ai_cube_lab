원기둥 좌표 — 회전목마의 주소

핵심 질문 — 둥근 회전목마 위의 자리를, 큐브 주소보다 더 자연스럽게 부르는 법은?

회전목마 위의 말은 「중심에서 2m, 입구에서 60° 돌아간 곳, 높이 1.5m」라고 부르는 게 편해요. 이렇게 거리·각도·높이로 부르는 주소가 원기둥 좌표 (s, φ, z)예요. 원자료 공식표의 둘째 기둥 「Cylindrical」이 바로 이것입니다.

(s, φ, z)원기둥 주소의 세 숫자
(0, 2, 3)(2, 90°, 3)의 큐브 주소
s = 2반지름 2인 원기둥 벽의 식 (큐브로는 x² + y² = 4)
360°φ가 한 바퀴 돌면 제자리

숫자 요약은 이 장의 예시 계산에서 나온 값입니다(실제 데이터가 아닌 설명용 값).

박사

오늘은 1:1 토론입니다. 주제: 「둥근 곳의 주소는 큐브 주소로 충분한가?」

인턴 모아

저는 원기둥 주소파예요! 회전목마에서 (x, y)로 자리 찾는 사람은 못 봤어요.

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 중심에서의 거리 s, 도는 각 φ, 높이 z로 점을 부르는 원기둥 좌표와, 큐브 주소로 바꾸는 공식(x = s·cos φ, y = s·sin φ)을 배웁니다.
  2. 왜 중요한가: 둥근 물체(관, 회전하는 날개, 소용돌이)에서는 원기둥 주소가 식을 훨씬 짧게 만들어요. 13장 소용돌이와 16장 공식표의 바탕이에요.
  3. 생활·현장에서는: 회전목마, 원형 경기장 좌석, 레이더 화면, 드릴로 뚫은 구멍의 위치가 원기둥 주소로 부르기 좋은 예예요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

영어 기호·약어 풀이 (펼치기)
  • s — 축(가운데 기둥)에서 수평으로 잰 거리
  • φ — 파이. x축에서 시계 반대 방향으로 돈 각
  • cos, sin — 삼각비 — 빗변 1일 때 밑변(cos)과 높이(sin)
  • ŝ, φ̂ — 바깥쪽 방향, 도는 방향의 단위 벡터

등장인물 — 선생님 1명, 조교 2명, 수강생 6명

선생님박사목소리는 크지만 판단은 계산대로. 막히는 곳에서 꼭 멈춰 줍니다.
조교 (의심 담당)초파리 연구원작지만 날카롭다. "정말 그래?" 하고 반례와 검산을 들고 옵니다.
조교 (확신 담당)주판봇공식과 빠른 계산을 좋아한다. 가끔 너무 빨리 확신합니다.
수강생 · 1조인턴 시아조용하고 꼼꼼한 정리 담당. 표와 그림으로 정리하는 걸 좋아해요.
수강생 · 2조인턴 모아상냥하고 잘 웃는다. 발표와 응원 목소리가 제일 커요.
수강생 · 1조조수 하루수식이 나오면 손을 번쩍 드는 질문 담당. 처음 오신 분의 눈높이.
수강생 · 1조미공개 X1정체는 비밀. 짧고 엉뚱한 질문을 던진다.
수강생 · 2조미공개 X2정체는 비밀. 조용히 그림을 그려 온다.
수강생 · 2조미공개 X3정체는 비밀. 숫자 세기와 손계산을 좋아한다.

용어 별명 카드 — 어려운 이름은 별명으로 기억하세요

원래 이름: 원기둥 좌표회전목마 주소(거리 s, 각 φ, 높이 z)

오늘의 수업 — 1:1 토론

1:1 토론

두 수강생이 서로 다른 입장을 맡아 맞붙고, 조교가 근거를 점검합니다. 오늘은 시아(큐브 주소파)와 모아(원기둥 주소파)의 토론이에요.

  1. 토론 규칙 소개: 각자 3분 주장 → 조교 질문 → 같은 문제를 두 주소로 풀어 비교
  2. 시아(큐브 주소파): 「x, y면 무엇이든 정확하다」
  3. 모아(원기둥 주소파): 「둥근 곳은 거리와 각도가 자연스럽다」
  4. 판정: 같은 점을 두 주소로 바꿔 보고, 식이 짧은 쪽 찾기
인턴 시아

큐브 주소는 어디서나 통해요. 공식 하나로 다 되잖아요.

인턴 모아

그럼 원기둥 벽을 x, y로 써 봐! 나는 「s = 2」 한 마디면 돼.

왜 이 주제를 배우나

1둥근 곳을 자연스럽게 부르려고

회전목마, 원형 탑, 소용돌이는 「중심에서 얼마나, 몇 도」가 먼저 떠올라요.

2식을 짧게 만들려고

반지름 2인 원기둥 벽은 큐브로 x² + y² = 4, 원기둥 주소로는 s = 2예요.

316장 공식표를 읽으려고

원자료 공식표의 둘째 기둥 전체가 원기둥 주소예요. 1/s 같은 이상한 항의 정체를 16장에서 풀어요.

큰 그림 — 지금 어디쯤 있나

앞에서 배운 것01장 큐브 주소 (x, y, z), 02장 단위 벡터
→
이번 장원기둥 주소 (s, φ, z) → 큐브 주소로 바꾸기 → 모양에 맞는 주소
→
다음에 쓰는 곳05장 구면 주소, 13장 소용돌이, 16장 좌표가 바뀌면 공식도 바뀐다
30초 복습 — 삼각비 (cos, sin)
빗변이 1인 직각삼각형에서 각 φ의 이웃 변이 cos φ, 마주 보는 변이 sin φ. cos 0° = 1, sin 0° = 0, cos 90° = 0, sin 90° = 1, cos 60° = 0.5, sin 60° ≈ 0.866.

같은 점에 이름이 여러 개 있을 수 있어요. 이름이 다를 뿐 점은 하나라는 게 이번 장의 핵심이에요.

1

1단계 · 회전목마의 자리 — (s, φ, z)

방법: 원기둥 좌표일상: 회전목마
박사

상황 질문 — 회전목마에서 친구에게 「내 자리」를 알려 줄 때, 어떤 말 세 개면 충분할까요?

왜 이 방법을 쓰나

  1. 문제 상황: 둥근 공간의 자리를 자연스럽게 부르고 싶어요.
  2. 앞 방법의 한계: 큐브 주소 (x, y)는 둥근 무대 위에서 「몇 바퀴째 어느 쪽」이 바로 보이지 않아요.
  3. 해법: 가운데 기둥에서의 거리 s, 기준선에서 돈 각 φ, 높이 z를 주소로 써요.
쉽게 말하면 — 「중심에서 얼마나, 몇 도 돌아서, 얼마나 높이」.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

φ가 360°를 넘으면 어떻게 돼요? 400°도 돼요?

학교 수학으로 보면: 중학교 「원과 부채꼴」의 반지름·중심각, 그리고 높이를 합친 주소예요.

식 조각읽는 법뜻
s에스축에서 수평 거리 (0 이상)
φ파이x축에서 시계 반대 방향으로 돈 각 (0° ~ 360°)
z제트높이 — 큐브 주소의 z와 같음
숫자로 한 번 해 보기

(s, φ, z) = (2, 60°, 1.5): 중심에서 2, 60° 돌아서, 높이 1.5

s가 같은 점들 → 원기둥 벽

φ = 400°는 360° + 40° → φ = 40°와 같은 자리

s = 0이면 φ를 아무리 바꿔도 축 위의 같은 점

조수 하루 (수강생)

한 바퀴 돌면 제자리라 각도는 360°까지만 쓰면 되네요. 가운데(s = 0)는 각도가 의미 없고요.

일상으로 치면

회전목마의 말 자리는 「기둥에서 2m, 입구에서 60°, 높이 1.5m」처럼 부르면 바로 찾아요.

수학에서는

원기둥 좌표 (s, φ, z): 축에서의 거리 s, 도는 각 φ, 높이 z. 원자료 ③의 가운데 기둥이에요.

박사

s, φ, z를 하나씩 움직여 보세요. 각각 어떤 모양으로 움직이나요?

주판봇

φ를 크게 할수록 점이 멀어지겠죠!

초파리 연구원

s는 그대로 두고 φ만 0°에서 360°까지 돌려 봐. 중심에서 거리가 바뀌어?

원기둥 좌표 실험 — 거리 s, 각 φ, 높이 z

풀이 — 한 걸음씩

  1. s를 움직이면 점이 축에서 멀어지거나 가까워져요(빨간 선).
  2. φ를 움직이면 점이 같은 반지름의 원을 따라 돌아요(보라 호).
  3. z를 움직이면 위아래로만 움직여요(초록 선). 큐브의 z와 똑같아요.
  4. s = 0으로 두고 φ를 돌려 보세요. 점이 움직이지 않아요.
이 단계의 한계 — 축 위(s = 0)에서는 φ가 정해지지 않아요. 16장 공식에 1/s가 있어서 s = 0에서 계산이 곤란해지는 것도 이 때문이에요.
박사의 해석 — 원기둥 주소는 「둥근 것의 대칭」을 그대로 담아요. 회전해도 s와 z는 변하지 않고 φ만 바뀌어요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ③의 가운데 기둥 Cylindrical (s, φ, z): 원기둥 그림의 빨간 s와 초록 φ. 척도 인자 1, s, 1.

2단계 · 큐브 주소로 바꾸기 — 삼각비가 다리

방법: 좌표 변환일상: 레이더 화면
박사

상황 질문 — 레이더 화면에는 「거리 2km, 방향 90°」로 비행기가 떠요. 지도(가로·세로)에 표시하려면 어떻게 바꿀까요?

왜 이 방법을 쓰나

  1. 문제 상황: 두 주소를 오가며 계산하고 싶어요.
  2. 앞 방법의 한계: 원기둥 주소로는 거리 공식(01장)을 바로 쓸 수 없어요.
  3. 해법: 빗변 s, 각 φ인 직각삼각형을 그리면 x = s·cos φ, y = s·sin φ. 거꾸로는 s = √(x² + y²).
쉽게 말하면 — 거리와 각도 → 가로·세로는 삼각비, 가로·세로 → 거리는 피타고라스.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

x = s·cos φ 에서 cos은 왜 x 쪽에 붙어요?

학교 수학으로 보면: 중학교 3학년 「삼각비」예요. 빗변 s, 각 φ인 직각삼각형의 밑변이 s·cos φ, 높이가 s·sin φ.

식 조각읽는 법뜻
x = s·cos φ엑스는 에스 코사인 파이바닥 그림자의 가로 성분
y = s·sin φ와이는 에스 사인 파이바닥 그림자의 세로 성분
s = √(x² + y²)에스는 루트…거꾸로 바꿀 때 (피타고라스)
숫자로 한 번 해 보기

(s, φ, z) = (2, 60°, 1.5)

x = 2 × cos 60° = 2 × 0.5 = 1

y = 2 × sin 60° ≈ 2 × 0.866 = 1.73

거꾸로: √(1² + 1.73²) = √(1 + 3) = 2 ✓ (1.73² ≈ 3)

조수 하루 (수강생)

빗변이 s인 삼각형을 그리니까 cos이 가로, sin이 세로인 게 보이네요.

일상으로 치면

레이더의 「거리·방향」을 지도의 「가로·세로」로 옮기는 건, 비스듬한 막대의 그림자 길이를 재는 일과 같아요.

수학에서는

좌표 변환: x = s·cos φ, y = s·sin φ, z = z. 거꾸로 s = √(x² + y²), φ는 점이 있는 쪽(사분면)을 보고 정해요.

박사

φ를 90°로 두고 x와 y가 얼마인지 읽어 보세요.

주판봇

(2, 90°, 3)의 x는 s니까 2!

초파리 연구원

φ가 90°면 점이 어느 축 위에 있는지 그림에서 봐.

두 주소 맞대기 — 원기둥 주소를 넣으면 큐브 주소가 나와요

풀이 — 한 걸음씩

  1. 아래 계산 줄에 x = s·cos φ, y = s·sin φ가 숫자로 나와요.
  2. φ = 0°면 점이 x축 위 → x = s, y = 0.
  3. φ = 90°면 점이 y축 위 → x = 0, y = s.
  4. φ = 180°면 x가 음수가 돼요. cos이 음수가 되는 쪽이에요.
이 단계의 한계 — φ를 x, y에서 되찾을 때 「기울기 y/x」만 보면 반대편(180° 차이) 점과 구별이 안 돼요. 점이 어느 쪽에 있는지 꼭 함께 봐야 해요.
박사의 해석 — 변환 공식은 「같은 점의 두 이름표」를 잇는 사전이에요. 16장에서 이 사전 덕분에 같은 그래디언트를 두 길로 계산해 검산해요.
삼각비가 가물가물하면 30초 복습 상자의 값 네 개만 보고 오세요. 그 값만으로 이 장을 다 풀 수 있어요.

3단계 · 모양에 맞는 주소 — 식이 짧아지는 쪽

방법: 좌표계 고르기일상: 방 번호 vs 좌석 번호
박사

상황 질문 — 원형 경기장 좌석을 「가로 몇 m, 세로 몇 m」로 부르면 어떤 불편이 생길까요?

왜 이 방법을 쓰나

  1. 문제 상황: 문제마다 계산이 가장 쉬운 주소를 고르고 싶어요.
  2. 앞 방법의 한계: 어떤 모양은 큐브 주소로 쓰면 제곱과 루트가 잔뜩 붙어요.
  3. 해법: 모양을 세 가지 주소로 다 써 보고, 식이 가장 짧은 주소를 골라요.
쉽게 말하면 — 모양의 대칭과 주소의 대칭을 맞춘다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

같은 원기둥 벽인데 식이 x² + y² = 4도 되고 s = 2도 된다니, 둘 다 맞아요?

학교 수학으로 보면: 같은 수를 분수 1/2, 소수 0.5로 쓰는 것과 같아요. 표기만 다르고 가리키는 것은 하나예요.

식 조각읽는 법뜻
x² + y² = 4큐브 주소의 식반지름 2인 원기둥 벽
s = 2원기둥 주소의 식같은 벽
φ = 90°원기둥 주소의 식y축 쪽으로 세운 반쪽 벽
숫자로 한 번 해 보기

원기둥 벽: x² + y² = 4 ↔ s = 2

바닥판 z = 1: 두 주소 모두 z = 1

공 껍질 x² + y² + z² = 4 ↔ s² + z² = 4 (구면이면 r = 2, 05장)

원뿔 z² = x² + y² ↔ z = s (위쪽)

조수 하루 (수강생)

모양이 둥글수록 원기둥 주소가 짧아지고, 네모날수록 큐브 주소가 짧아지네요.

일상으로 치면

원형 경기장 좌석은 「몇 구역(각도), 몇 열(거리)」로 부르고, 네모난 교실 자리는 「몇째 줄, 몇째 자리」로 불러요.

수학에서는

같은 모양이라도 원기둥 좌표로 쓰면 식이 짧아질 수 있어요. 문제의 대칭에 맞는 주소를 고르면 계산이 쉬워져요.

박사

모양을 바꿔 가며 세 주소의 식을 비교해 보세요.

인턴 시아

바닥판은 큐브 주소가 더 짧네요. 모아 말이 다 맞는 건 아니에요!

초파리 연구원

공 껍질은 어느 주소가 제일 짧아? 다음 장 예고야.

같은 모양, 세 가지 주소 식

풀이 — 한 걸음씩

  1. 원기둥 벽은 원기둥 주소로 s = 2, 한 마디예요.
  2. 바닥판은 세 주소 중 큐브·원기둥이 z = 1로 짧아요.
  3. 공 껍질은 구면 주소로 r = 2가 가장 짧아요(05장).
  4. 토론 판정: 「모양에 따라 다르다」 — 시아와 모아 모두 반쯤 맞았어요.
이 단계의 한계 — 식이 짧아도 계산 공식(기울기·발산)은 둥근 주소에서 더 복잡해져요. 그 대가를 16장에서 봐요.
박사의 해석 — 좋은 주소는 문제의 대칭을 닮은 주소예요. AI에서도 데이터의 모양에 맞게 좌표(특성)를 바꾸면 문제가 쉬워지는 일이 많아요.

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

시아가 AI에게 「점 (x, y) = (−1, 1)의 원기둥 각 φ는?」이라고 물었더니 이렇게 답했어요.

AI 답변: φ = arctan(y / x) = arctan(1 / −1) = arctan(−1) = −45°, 즉 315°입니다.
박사

AI가 공식 하나로 각도를 구했다면, 점을 직접 그려 어느 쪽에 있는지 확인하세요. 공식보다 그림이 먼저입니다.

조교 대결 — (s, φ, z) = (2, 90°, 3)의 x는?

원기둥 주소를 큐브 주소로 바꾸는 문제로 두 조교가 맞붙었어요.
