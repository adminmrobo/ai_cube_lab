라플라시안 — 평균 휨과 이웃 평균

핵심 질문 — 휨을 숫자 하나로 줄이면 무엇을 알 수 있고, 무엇을 놓칠까?

14장 헤시안은 휨을 표로 적었어요. 그 대각선을 더한 숫자 하나가 라플라시안 ∇²f예요. 「평균 휨」이고, 「이웃 평균보다 내가 얼마나 낮은가」이기도 해요. 원자료 ②의 넷째 상자이고, 사진 경계 찾기와 열이 퍼지는 계산에 쓰여요.

4f = x² + y²의 라플라시안 (그릇)
−4f = −(x² + y²)의 라플라시안 (돔)
0f = x² − y²의 라플라시안 (말안장)
6f = x² + y² + z²의 라플라시안 (3차원)

숫자 요약은 이 장의 예시 계산에서 나온 값입니다(실제 데이터가 아닌 설명용 값).

박사

오늘은 찬반 토론입니다. 주장: 「라플라시안이 0이면 그 자리는 평평하다.」

미공개 X3

…반대편이에요. 숫자로 반례를 가져왔어요.

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 2차 편미분을 더한 라플라시안이 「평균 휨」이자 「이웃 평균과의 차이」라는 것, 그리고 사진의 경계 찾기와 열이 퍼지는 규칙에 쓰인다는 것을 배웁니다.
  2. 왜 중요한가: 라플라시안은 이미지 처리(경계·선명화), 그래프 데이터 분석(이웃과의 차이), 확산 모델과 열·전기 같은 물리 계산의 공통 도구예요.
  3. 생활·현장에서는: 사진 앱의 「선명하게」, 뜨거운 국이 식으며 고르게 되는 것, 소문이 이웃으로 퍼지는 모형이 모두 라플라시안으로 설명돼요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

영어 기호·약어 풀이 (펼치기)
  • ∇²f — 라플라시안 — ∂²f/∂x² + ∂²f/∂y² (+ ∂²f/∂z²)
  • Δf — 라플라시안의 다른 기호 (세모 델타)
  • 이산 라플라시안 — 격자 위에서: 이웃 합 − 4 × 가운데
  • k — 열이 퍼지는 빠르기

등장인물 — 선생님 1명, 조교 2명, 수강생 6명

선생님박사목소리는 크지만 판단은 계산대로. 막히는 곳에서 꼭 멈춰 줍니다.
조교 (의심 담당)초파리 연구원작지만 날카롭다. "정말 그래?" 하고 반례와 검산을 들고 옵니다.
조교 (확신 담당)주판봇공식과 빠른 계산을 좋아한다. 가끔 너무 빨리 확신합니다.
수강생 · 1조인턴 시아조용하고 꼼꼼한 정리 담당. 표와 그림으로 정리하는 걸 좋아해요.
수강생 · 2조인턴 모아상냥하고 잘 웃는다. 발표와 응원 목소리가 제일 커요.
수강생 · 1조조수 하루수식이 나오면 손을 번쩍 드는 질문 담당. 처음 오신 분의 눈높이.
수강생 · 1조미공개 X1정체는 비밀. 짧고 엉뚱한 질문을 던진다.
수강생 · 2조미공개 X2정체는 비밀. 조용히 그림을 그려 온다.
수강생 · 2조미공개 X3정체는 비밀. 숫자 세기와 손계산을 좋아한다.

오늘의 수업 — 찬반 토론

찬반 토론

「라플라시안이 0이면 그 자리는 평평하다」는 주장을 두고 찬성(주판봇 지지, 모아·X2)과 반대(초파리 지지, 시아·X3)로 나뉘어 토론해요.

  1. 주장 발표: 「라플라시안 0 = 평평」
  2. 찬성(모아·X2): 그릇 +, 돔 −이니 0이면 평평한 중간
  3. 반대(시아·X3): 말안장 반례와 이웃 평균 해석
  4. 판정 + 조교 대결: 말안장 x² − y²의 라플라시안
인턴 모아

찬성! 그릇은 +4, 돔은 −4, 그러니까 0은 평평한 판이죠!

인턴 시아

반대합니다. 「합」이 0인 것과 「모두」 0인 건 달라요.

왜 이 주제를 배우나

1휨을 한 숫자로 요약하려고

헤시안 표 전체 대신 「평균적으로 위로 휘었나, 아래로 휘었나」만 필요할 때가 많아요.

2이웃과 비교하려고

라플라시안은 「내 값이 이웃 평균보다 얼마나 낮은가」예요. 사진·그래프·격자 데이터에 그대로 쓸 수 있어요.

3퍼지는 현상을 계산하려고

열·잉크·소문이 퍼지는 속도는 라플라시안에 비례해요. 봉우리는 낮아지고 골짜기는 채워져요.

큰 그림 — 지금 어디쯤 있나

앞에서 배운 것14장 헤시안 (휨의 표), 12장 발산
→
이번 장∇²f = 대각선 합(평균 휨) → 이웃 평균 → 경계 찾기 → 열 퍼짐
→
다음에 쓰는 곳16장 원기둥·구면 좌표의 라플라시안 공식, 17장 ∇·(∇f) = ∇²f
30초 복습 — 헤시안
2변수 헤시안 a, b], [b, c에서 a = ∂²f/∂x², c = ∂²f/∂y² (14장). 대각선 합 = a + c.

「합이 0」과 「모두 0」은 다르다 — 이 한 줄이 오늘 토론의 핵심이에요.

1

1단계 · 평균 휨 — 헤시안 대각선의 합

방법: 라플라시안 ∇²f일상: 그릇과 돔
박사

상황 질문 — 그릇은 사방으로 위로 휘고, 돔은 사방으로 아래로 휘어요. 말안장은요? 휨을 평균 내면 몇이 될까요?

왜 이 방법을 쓰나

  1. 문제 상황: 여러 방향의 휨을 숫자 하나로 요약하고 싶어요.
  2. 앞 방법의 한계: 헤시안 표는 정보가 많지만 「대체로 어느 쪽으로 휘었나」를 한눈에 보기 어려워요.
  3. 해법: 축 방향 2차 편미분들을 더해요: ∇²f = ∂²f/∂x² + ∂²f/∂y². 헤시안의 대각선 합이에요.
쉽게 말하면 — 가로 휨 + 세로 휨 = 평균 휨(의 두 배).

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

∇²f는 ∇f를 제곱하는 거예요?

학교 수학으로 보면: 제곱이 아니라 「∇를 두 번」 쓴다는 표시예요. 그래디언트(∇f)를 구하고, 그 발산(∇·)을 구하면 ∇²f가 돼요(17장).

식 조각읽는 법뜻
∇²f = ∂²f/∂x² + ∂²f/∂y²라플라시안축 방향 휨의 합
> 0평균적으로 위로 휨그릇 쪽, 이웃보다 낮음
< 0평균적으로 아래로 휨돔 쪽, 이웃보다 높음
숫자로 한 번 해 보기

그릇 x² + y²: 2 + 2 = 4

돔 −(x² + y²): −2 − 2 = −4

말안장 x² − y²: 2 + (−2) = 0 — 평평하지 않은데 0!

3차원 공 모양 x² + y² + z²: 2 + 2 + 2 = 6

조수 하루 (수강생)

말안장은 위로 휜 만큼 아래로 휘어서 합이 0이네요. 0이라고 평평한 게 아니었어요.

일상으로 치면

그릇의 휨을 모두 더하면 +, 돔은 −, 말안장은 위로 휜 만큼 아래로 휘어서 0이 될 수 있어요.

수학에서는

라플라시안 ∇²f = 헤시안의 대각선 합 = 평균 휨(의 n배). 원자료 ②: 「∇²f > 0: bowl, curves up on average / ∇²f < 0: dome, curves down on average」. 「on average」(평균)가 핵심이에요.

인턴 모아

(찬성) a = 2, c = −2로 두면 0이 나와요. 이게 평평한 거 아닌가요?

주판봇

0이면 평평! 찬성편 승리!

초파리 연구원

그림을 봐. 그게 평평한 판이야, 말안장이야?

평균 휨 실험 — a, b, c와 라플라시안

풀이 — 한 걸음씩

  1. 라플라시안 = a + c (헤시안 대각선 합)이에요. b(섞인 항)는 들어가지 않아요.
  2. a = 2, c = −2면 0이지만 모양은 말안장이에요.
  3. a = 3, b = 2, c = 1이면 라플라시안 4 > 0인데도 말안장이에요(det = 3 − 4 < 0).
  4. 라플라시안이 알려 주는 건 「평균」뿐이에요. 모양을 확실히 가르려면 헤시안 전체가 필요해요.
이 단계의 한계 — 라플라시안은 정보를 하나로 줄인 만큼 잃는 것도 있어요. 바닥 판정은 14장 헤시안으로 해야 해요.
박사의 해석 — 라플라시안은 「대체로 위로 휘었나(이웃보다 낮나)」를 빠르게 알려 주는 요약 숫자예요. 요약은 편리하지만, 결론을 내리기 전에 원래 표를 확인하는 습관이 필요해요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ②의 Laplacian: ∇²f = ∂²f/∂x² + ∂²f/∂y² + ∂²f/∂z², 그릇(∇²f > 0)과 돔(∇²f < 0) 그림.

2

2단계 · 이웃 평균과 비교 — 숫자 격자의 라플라시안

방법: 이산 라플라시안일상: 반 평균과 내 점수
박사

상황 질문 — 내 점수가 짝꿍 넷(앞·뒤·좌·우)의 평균보다 낮으면, 나는 「골짜기」에 있는 걸까요?

왜 이 방법을 쓰나

  1. 문제 상황: 미분 공식 없이, 숫자 격자(사진·지도 데이터)에서 라플라시안을 계산하고 싶어요.
  2. 앞 방법의 한계: 컴퓨터 속 데이터는 매끄러운 식이 아니라 격자 위 숫자들이에요.
  3. 해법: 가운데 수와 이웃 넷을 비교해요: 이웃 합 − 4 × 가운데 = 4 × (이웃 평균 − 가운데). 2차 편미분을 격자로 흉내 낸 거예요.
쉽게 말하면 — 이웃 평균보다 낮으면 +, 높으면 −.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

「이웃 합 − 4 × 가운데」가 어떻게 2차 미분이에요?

학교 수학으로 보면: 중학교 「평균」과 「차이」예요. 가로 방향으로 (왼쪽 − 가운데) + (오른쪽 − 가운데)는 「기울기의 변화」 = 2차 미분을 흉내 낸 값이에요. 세로도 더하면 라플라시안.

식 조각읽는 법뜻
왼 + 오 − 2 × 가운데가로 2차 차분∂²f/∂x²를 흉내 냄
위 + 아래 − 2 × 가운데세로 2차 차분∂²f/∂y²를 흉내 냄
이웃 합 − 4 × 가운데이산 라플라시안= 4 × (이웃 평균 − 가운데)
숫자로 한 번 해 보기

그릇 격자 f = x² + y²의 가운데 0, 이웃 1, 1, 1, 1

1 + 1 + 1 + 1 − 4 × 0 = 4 (매끄러운 식의 값 4와 같음)

봉우리: 가운데 4, 이웃 0, 0, 0, 0 → 0 − 16 = −16

안장 격자 x² − y²의 가운데 0, 이웃 1, 1, −1, −1 → 0

조수 하루 (수강생)

이웃 평균이랑 비교만 하면 되니까 미분을 몰라도 계산할 수 있네요!

일상으로 치면

반에서 내 점수가 앞·뒤·좌·우 친구들 평균보다 낮으면 나는 「움푹한 자리」, 높으면 「솟은 자리」예요.

수학에서는

격자의 이산 라플라시안 = 이웃 합 − 4 × 가운데 = 4 × (이웃 평균 − 가운데). 매끄러운 라플라시안을 격자 위에서 흉내 낸 것이에요.

인턴 시아

(반대) 안장 모양 단추를 눌러 보세요. 가운데 값이 이웃 평균과 같아서 0이에요. 그래도 평평하진 않죠.

미공개 X2

(찬성) …숫자를 하나 올리면 금방 0이 아니게 돼요.

초파리 연구원

가운데 수를 눌러 하나씩 올려 봐. 라플라시안이 어떻게 변해?

숫자 격자 — 가운데와 이웃 넷 비교

풀이 — 한 걸음씩

  1. 노란 수가 가운데, 파란 수가 이웃 넷이에요. 아래 줄에 계산이 나와요.
  2. 「그릇 모양」 단추를 누르고 가운데를 보면 라플라시안 4 — 매끄러운 식과 같아요.
  3. 「안장 모양」에서는 어디서나 0이에요. 평균 휨 0의 격자판이에요.
  4. 가운데 수를 하나 올리면 라플라시안이 4씩 줄어요(이웃보다 높아지니까).
이 단계의 한계 — 이웃을 넷(상하좌우)만 썼어요. 대각선 이웃까지 쓰는 등 여러 흉내 방법이 있고, 결과가 조금씩 달라요.
박사의 해석 — 이산 라플라시안은 「나와 이웃의 차이」예요. 그래프(관계망) 데이터에서도 같은 생각으로 「이웃과 얼마나 다른가」를 재요(그래프 라플라시안).
격자 계산이 단순해서 오히려 의심스러울 수 있어요. 정말 그게 다예요.

3단계 · 사진의 경계 찾기 — 라플라시안 필터

방법: 라플라시안 필터일상: 사진 앱의 「선명하게」
박사

상황 질문 — 흑백 사진에서 물체의 테두리만 골라내려면, 픽셀 숫자의 어떤 성질을 보면 될까요?

왜 이 방법을 쓰나

  1. 문제 상황: 사진에서 물체의 경계를 자동으로 찾고 싶어요.
  2. 앞 방법의 한계: 밝기 숫자를 하나씩 보면 「어디가 경계인지」 알 수 없어요.
  3. 해법: 모든 픽셀에 이산 라플라시안을 계산해요. 밝기가 고른 곳은 0, 밝기가 갑자기 바뀌는 경계에서만 값이 생겨요.
쉽게 말하면 — 이웃과 같으면 0, 다르면 경계.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

사진도 미분할 수 있어요? 사진은 식이 없잖아요.

학교 수학으로 보면: 앞 단계의 격자 계산을 픽셀마다 똑같이 하면 돼요. 식이 없어도 이웃 숫자만 있으면 계산돼요.

식 조각읽는 법뜻
밝기 격자흑백 사진픽셀마다 밝기 숫자
라플라시안 필터이웃 합 − 4 × 가운데모든 픽셀에 같은 계산
0이 아닌 곳경계밝기가 바뀌는 테두리
숫자로 한 번 해 보기

네모 물체 안쪽: 9, 이웃도 모두 9 → 36 − 36 = 0

배경: 1, 이웃도 1 → 0

물체 테두리 바로 안쪽: 9, 이웃 9, 9, 9, 1 → 28 − 36 = −8

테두리 바로 바깥: 1, 이웃 1, 1, 1, 9 → 12 − 4 = 8 → 경계 양쪽에 +와 −

조수 하루 (수강생)

고른 곳은 다 지워지고 테두리만 남네요. 사진에 쓰는 미분이라니 신기해요.

일상으로 치면

사진 앱의 「선명하게」는 경계를 찾아 그 차이를 조금 더 키워요. 경계 찾기의 바탕이 라플라시안이에요.

수학에서는

라플라시안 필터는 모든 픽셀에 이산 라플라시안을 계산해, 밝기가 고른 곳은 0, 경계는 +/−로 표시해요. AI 이미지 처리의 고전적인 첫 단계예요.

미공개 X3

(반대) 안쪽은 0인데 평평한 게 맞아요. 하지만 테두리는 0이 아니죠. 0의 뜻을 정확히 봐야 해요.

주판봇

그럼 0인 곳은 다 쓸모없는 곳이네요!

초파리 연구원

0인 곳은 「이웃과 같은 곳」이야. 쓸모없는 게 아니라 고른 곳.

경계 찾기 — 작은 흑백 사진에 라플라시안 필터

풀이 — 한 걸음씩

  1. 왼쪽은 원래 사진(숫자가 클수록 진함), 오른쪽은 라플라시안 결과예요.
  2. 네모와 동그라미의 안쪽, 배경은 모두 흰색(0)이에요.
  3. 테두리에서만 빨강(+)과 파랑(−)이 짝지어 나타나요 — 바깥쪽이 +, 안쪽이 −.
  4. 이 결과를 사진에 조금 빼 주면(가운데를 이웃보다 더 강조) 사진이 선명해 보여요.
이 단계의 한계 — 실제 사진에는 잡음(작은 얼룩)이 많아서 라플라시안만 쓰면 잡음까지 경계로 잡혀요. 보통 먼저 사진을 부드럽게 한 뒤 써요.
박사의 해석 — 라플라시안이 0이 아닌 곳은 「주변과 다른 곳」이에요. 경계·얼룩·특이점을 찾는 모든 일의 출발점이에요.
원자료 인포그래픽 보기 (영어 그림)

원자료 ②의 Laplacian 상자(그릇과 돔)를 격자 사진에 적용한 예예요.

4단계 · 열이 퍼지는 법 — 봉우리는 낮아지고 골짜기는 채워진다

방법: 열 방정식(확산)일상: 뜨거운 국이 고르게 식기
박사

상황 질문 — 쇠막대 한가운데만 불로 달구고 두면, 시간이 지나며 온도는 어떻게 바뀔까요?

왜 이 방법을 쓰나

  1. 문제 상황: 열·잉크처럼 퍼지는 현상이 시간에 따라 어떻게 변하는지 계산하고 싶어요.
  2. 앞 방법의 한계: 「뜨거운 곳은 식고 차가운 곳은 데워진다」는 말만으로는 얼마나 빨리 변하는지 알 수 없어요.
  3. 해법: 온도 변화 = k × 라플라시안. 이웃보다 뜨거우면(라플라시안 −) 식고, 이웃보다 차가우면(+) 데워져요.
쉽게 말하면 — 이웃 평균 쪽으로 조금씩 다가가기.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

라플라시안이 시간이랑 무슨 상관이에요?

학교 수학으로 보면: 앞 단계의 「이웃 평균 − 나」를 시간마다 조금씩 더해 주는 규칙이에요. 1차원 막대라 이웃은 왼쪽·오른쪽 둘이에요.

식 조각읽는 법뜻
다음 온도 = 지금 + k × (왼 + 오 − 2 × 나)열이 퍼지는 규칙1차원 라플라시안만큼 변함
봉우리라플라시안 −온도가 내려감
k ≤ 0.5계산 안정 조건넘으면 계산이 들쭉날쭉 튐
숫자로 한 번 해 보기

온도 0, 9, 0 (가운데만 뜨거움), k = 0.25

가운데: 9 + 0.25 × (0 + 0 − 18) = 4.5

양옆: 0 + 0.25 × (9 + 0 − 0) = 2.25 (바깥 이웃은 0이라고 가정)

합 2.25 + 4.5 + 2.25 = 9 — 열의 총량은 그대로, 고르게 퍼짐

조수 하루 (수강생)

뜨거운 곳은 이웃 평균 쪽으로 내려가고, 차가운 곳은 올라오네요. 라플라시안이 「고르게 만드는 힘」이었어요.

일상으로 치면

뜨거운 국을 그릇에 담아 두면, 뜨거운 가운데는 식고 가장자리는 데워지며 점점 고른 온도가 돼요.

수학에서는

열 방정식: 온도의 시간 변화 = k × 라플라시안. 봉우리는 낮아지고 골짜기는 채워져요. AI의 확산 모델은 이런 「퍼짐」을 거꾸로 되돌리는 법을 배워 그림을 만들어요(여기서는 단순하게 소개만).

박사

「시간 흐르게」를 눌러 봉우리 두 개가 어떻게 변하는지 보세요. k를 0.55로도 해 보세요.

인턴 모아

봉우리가 낮아지는 속도가 처음엔 빠르고 나중엔 느려요. 왜죠?

초파리 연구원

처음엔 이웃과 차이(라플라시안)가 크고, 고르게 될수록 작아지니까.

열이 퍼지는 막대 — 라플라시안만큼 변하기

풀이 — 한 걸음씩

  1. 빨간 곡선과 아래 색 띠가 막대의 온도예요. 봉우리 두 개(뜨거운 곳)가 있어요.
  2. 시간이 흐르면 봉우리는 낮아지고 넓게 퍼져요. 전체 열의 합은 거의 그대로예요.
  3. 봉우리가 낮아질수록 이웃과 차이가 작아져 변화도 느려져요.
  4. k가 0.5를 넘으면 계산이 들쭉날쭉 튀어요 — 실제 열이 아니라 계산 방법의 한계예요(10장 학습률과 비슷해요).
이 단계의 한계 — 막대 끝을 「이웃과 같은 온도」로 둔 단순한 모형이에요. 실제 막대는 공기로 열이 빠져나가는 등 조건이 더 있어요.
박사의 해석 — 라플라시안은 「고르게 만드는 힘」이에요. 그래서 라플라시안이 0인 상태(이웃 평균 = 나)는 더 이상 변하지 않는 「평형」 상태예요.

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

모아가 AI에게 「f(x, y) = x² − y²의 원점에서 라플라시안이 0이에요. 이 점의 모양은?」이라고 물었더니 이렇게 답했어요.

AI 답변: 라플라시안이 0이므로 이 점 주변은 휘어 있지 않은 평평한 평면입니다.
박사
